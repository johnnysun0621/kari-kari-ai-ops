# 任務提交、檔案大小與審核通知

這份文件記錄 `/我的任務` → `提交任務` 與 `/審核提交` 的產品規則。  
核心原則：**所有交件一律上傳到 Bot 提供的公司 Google Drive 資料夾，只有這一種交法。**

## 核心決策

`提交方式` 全部停用（2026-10-11）（決議見規則頁 M4-03）。不再有「貼雲端連結」與「純文字」：
藝人貼自己的連結時檔案不會進公司 Drive、也不會被歸檔，與「所有檔案最終都在公司 Drive」直接衝突。

藝人只要執行 `/我的任務` → `提交任務`，選任務，就會拿到這次提交專用的公司 Drive 資料夾。
文字類的內容（心得、企劃想法）請藝人存成檔案（Word、PDF、文字檔）再上傳。

## Notion 控制欄位

| Notion 欄位 | 用途 |
|---|---|
| `是否開放提交` | 是否出現在 `/我的任務` → `提交任務` 清單 |
| `提交期限` | 第一次提交期限；控方直接在 Notion 設定 |
| `修改期限` | 審核退回時由 Discord 審核流程寫入，與首次提交期限分開 |
| `審核人員` | 指定誰審；每日催辦會私訊審核人員，沒填就發到控方頻道 |
| `Google Drive Folder` | 單一藝人任務首次提交時由 Bot 自動回寫；也可手動指定並優先於藝人專區預設路徑。多人任務的各藝人連結會寫入任務內頁的「Drive 資料夾索引」段落。 |
| `最新提交 URL` | Bot 提交後回寫最新一筆 Notion Submission 頁面 |

`提交方式` 欄位程式已不讀取，Notion 端也已刪除（2026-10-13 確認）。

## Discord 操作流程

1. 藝人在 `任務查詢入口` 執行 `/我的任務` → `提交任務`。
2. Bot 讀取該藝人的可提交 Tasks，列出任務清單與任務內頁的摘要。
3. 藝人選任務後，Bot 用只有本人看得到的訊息給出這次提交的 Drive 版本資料夾，格式為 `任務名稱_YYYY.MM.DD_ver.N`。
4. 藝人把檔案上傳到該資料夾，按「我已上傳到 Drive」。Bot 只驗證這個入口建立之後新增的檔案。
5. 驗證失敗時，藝人確認上傳位置後可再按一次；選錯任務可返回任務清單。
6. 成功後寫入 `Submissions & File Index`，並把 Task 轉為 `待審核`。
7. Bot 不設定固定審核期限；提交滿 24 小時仍未審核，就列入**每天 10:00 的每日催辦**，私訊指定審核人員（沒填或聯絡不到就發到 `營運內部通知`）。
8. 控方在 `營運內部通知` 收到新提交通知。

Drive 驗證入口有效時間為 3 小時（`FILE_UPLOAD_WAIT_MINUTES`）。逾時要重新進入提交流程，資料夾本身不會關。

**重新進入同一筆任務沿用同一個版本夾（2026-10-18）**：上傳入口是 ephemeral 訊息，藝人切去 Drive 上傳、回來訊息常已消失，只能重新進入。3 小時內同一人重新進入同一筆任務，Bot 沿用上次的 `ver.N` 資料夾與起算時間，所以先前上傳的檔案驗證得到；紀錄存在 `.state/pending_drive_uploads.json`，bot 重啟也找得回來。提交成功後清掉紀錄，下次再交才開下一個 ver。修正前每次重新進入都會開新的 ver（QA 時一筆任務開到 ver.4，前三個是空的）。

Bot 不收 Discord 附件，藝人直接丟附件會被提醒改走上面的流程。

### 資料夾結構（2026-10-18 上線）

規則全文見規則頁 M4-07、M4-16；實作卡「M4-07：Drive 歸檔改照 Notion 專案分層」，前置是 Drive 授權修好。

```
<藝人專區>/
├─ <專案名稱>/                                ← 任務的「關聯專案」名稱；沒掛專案 → 未分專案/
│  └─ <YYYY.MM.DD_任務名稱>/                   ← 日期取截止日，沒有用 Notion 建立日
│     ├─ <任務名稱_YYYY.MM.DD_ver.N>/          ← 每次提交一個版本夾
│     └─ 老師回饋/老師回饋_YYYY.MM.DD_ver.N/
└─ 未分專案/
```

- 專案夾名稱照 Notion 原字串（不安全字元換成 `_`、最多 70 字）；掛多個專案用第一個。
- 拿掉舊的「任務類型夾」與「YYYY-MM」兩層。
- 任務有填 `Google Drive Folder` → 直接用；第一次提交後 Bot 回寫，所以同一任務之後一律回到同一個任務夾。
- **專案建好後盡量不要改名**：改名後，之後第一次提交的任務會在新名稱的夾，已交過的留在舊夾。
- 既有檔案不搬（2026-10-13 時沒有任何任務已回寫 `Google Drive Folder`）。
- Submissions 的 `檔案類型`：先看任務類型（課程時間&作業繳交→課程作業、創作交付→Demo、企劃提案→企劃書、錄音→錄音檔），對不到看專案類型（藝人外部商業合作／商務合作→業配素材、課程培訓→課程作業、內容企劃→企劃書、作品製作→Demo），都對不到 → 其他。

## 檔案傳輸原則

目前產品以「藝人不需付費、Bot 不下載大型作業」為前提：

- 所有檔案都直接上傳到 Bot 提供的公司 Drive 資料夾，不經過 Discord，不要求藝人購買 Nitro。
- Google Drive 可承載圖片、文件、Stem、DAW 專案、影片與大型音檔。
- 不接受藝人自己的雲端連結。檔案若已在藝人自己的 Drive，請藝人下載後上傳到公司資料夾。

檔案提交不接受截圖佐證，因為截圖不能直接讓老師或控方開檔審核；必須使用可開啟的 Drive 檔案或資料夾。

## Bot 寫入資料

成功提交後：

- 建立一筆 `Submissions & File Index`。
- `提交來源 = Discord`。
- `審核狀態 = 待審核`。
- `權限等級 = 藝人本人`。
- 同任務舊提交取消 `是否最新版`。
- Task `任務狀態` 轉為 `待審核`。
- Task `最新提交 URL` 回寫最新一筆 Notion Submission 頁面；公司 Drive 連結保留在 Submission 的 `Drive URL`。
- 控方在 `營運內部通知` 收到新提交通知。

檔案提交額外寫入：

- `Drive URL`
- `Drive File ID`
- `原始檔名`
- `檔案大小 MB`

Drive 上的檔名會由 Bot 自動加上辨識前綴：

- 藝人提交檔案：`{藝人名稱}_{任務名稱}_{原檔名}`
- 老師批改檔：`老師回饋_{提交名稱}_{原檔名}`

Bot 會清理 `/`、`:`、`?` 等不適合放檔名的字元；Notion `原始檔名` 仍保留藝人上傳時的原檔名。

## 審核與回饋通知

控方可在 Discord 使用 `/審核提交` 審核最新版提交：

1. 控方在 `營運內部通知` 執行 `/審核提交`。
2. 選擇待審核提交。
3. 選錯時可按「返回審核清單」；第一層可取消。
4. Bot 顯示 Drive 連結、Notion 提交頁與關聯任務連結。
5. 選 `通過`、`需修改` 或 `退回`。
6. 可填給藝人的回饋，例如「這次很好」或「請重修副歌音準」。
7. Bot 更新 Submissions、同步更新 Task 狀態，並 DM 藝人審核結果。
8. `需修改`／`退回` 時由審核人輸入 1～7 天修改期限；停在 `需修改` 期間每天 10:00 併入每日催辦提醒藝人，修改期限一過通知控方一次。
9. 藝人重新提交後，Task 轉回 `待審核` 並清除本輪 `修改期限`；原始 `提交期限` 不覆蓋、不重啟提醒。
10. 若要附批改檔，按 `附批改檔`；不需要時按 `不需補批改檔`。

批改檔規則：

- 批改檔統一使用老師回饋 Drive 資料夾。
- Bot 會歸檔到 `藝人專區/專案名稱/YYYY.MM.DD_任務名稱/老師回饋/老師回饋_YYYY.MM.DD_ver.N/`；任務已回寫 `Google Drive Folder` 時直接放在那個任務夾的 `老師回饋/` 底下。
- 任務沒有截止日時，日期會使用 Notion 任務頁的建立日期。
- 老師可以連續上傳多個批改檔，全部上傳後按「完成回饋」；這些檔案會集中在同一個回饋資料夾。
- 批改檔 Drive 連結會併入 Submissions 的 `審核回饋` 文字，不新增 schema。
- Bot 會產生對應藝人的老師回饋 Drive 資料夾；老師上傳後按 `貼 Drive 連結補回饋`。
- `貼 Drive 連結補回饋` 會把批改檔連結寫入 `審核回饋` 並通知藝人。
- 老師切去 Drive 上傳、回來時 ephemeral 訊息已消失：入口 3 小時內，老師在同一頻道發任何訊息，Bot 就回一則帶「貼 Drive 連結補回饋／完成回饋」按鈕的訊息（只有原審核人按得動）。已審過的提交不會再出現在 `/審核提交`，所以這是唯一的回頭路（2026-10-18）。
- 通過、需修改、退回與後續批改檔通知都**不附 Notion 連結**（2026-09-18 起，藝人端零 Notion 入口）；DM 內含任務名稱、審核結果、老師回饋與 Drive 批改檔連結，藝人要看任務細節用 `/我的任務`。
- 審核人按「不需補批改檔」後，整組批改檔按鈕會從訊息移除，避免完成後又誤開附件流程。
- 舊 Submission 若缺少 `關聯任務`，Bot 會用 Tasks 的 `最新提交 URL` 反查原 Task，再建立老師回饋資料夾。

Task 狀態同步：

| 審核結果 | Task 狀態 |
|---|---|
| `通過` | `已完成` |
| `需修改` | `需修改` |
| `退回` | `需修改` |

Notion 端手動審核也支援：

- 老師或控方在 Notion 將 `審核狀態` 改成 `通過` / `需修改` / `退回`。
- 若同時填了 `審核回饋`、`審核者` 或 `審核來源` 任一欄，Bot 背景 loop 會通知藝人。
- 通知成功後 Bot 回寫 `審核通知時間`，避免重複通知。

## Submissions 建議欄位

既有欄位：

- `提交名稱`
- `提交藝人`
- `關聯任務`
- `提交來源`
- `提交類型`
- `檔案類型`
- `Drive URL`
- `備註`
- `Drive File ID`
- `原始檔名`
- `檔案大小 MB`
- `提交時間`
- `是否最新版`
- `審核狀態`
- `權限等級`

審核通知需要新增 / 確認：

- `審核回饋`：rich text
- `審核者`：rich text
- `審核來源`：select，例如 `Discord`、`Notion`
- `審核通知時間`：date

常見錯誤：

- Discord 顯示「審核寫入 Notion 失敗」時，通常是 `Submissions & File Index` 少了上述任一審核欄位。
- 先補齊欄位後，再重新執行 `/審核提交`。

## 使用者說明文案基準

給藝人的說法：

> 請先執行 `/我的任務` → `提交任務`，選擇你要交的任務。  
> 選任務後，把檔案上傳到 Bot 提供的公司 Drive 資料夾，再按「我已上傳到 Drive」。文字內容請存成檔案再上傳。
> 提交後會進入待審核，審核結果和老師回饋會再私訊通知你。

給控方的說法：

> 要讓藝人交件，在 Notion 勾 `是否開放提交`，填 `提交期限` 與 `審核人員`。  
> 交法只有一種：上傳到 Bot 提供的公司 Drive 資料夾，不需要設定 `提交方式`。
