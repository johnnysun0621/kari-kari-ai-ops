# 修改或刪除已回報的時段

送出的只是「可以配合的時間」，不是排定的行程，隨時可以改，**不用找公司**。

## 刪掉時段

1. 到 `時間管理` 打 **`/管理可配合時間`**。
2. 從 **選擇要管理的月份…** 選月份。
3. 從 **選擇要刪除的既有時段（可多選）…** 勾要刪的時段。
4. 按 **🗑️ 刪除選取時段**。看到「🗑️ 已刪除並保存以下時段」就完成了。

## 補填新的時段

1. 同上，打開 `/管理可配合時間` 選月份。
2. 按 **➕ 新增／補填日期**。
3. 接著跟「回報下個月可配合時間」第 2 步以後一樣。

## 改時間

先刪掉舊的，再補填新的。

改完按 **✅ 完成並退出**。

> 💡 打開 `/管理可配合時間` 時，小律會順便把你重疊、重複的時段合併好。
