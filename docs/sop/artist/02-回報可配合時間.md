# 每月回報可配合時間

每個月公司會發起一次收集，你會在 `時間管理` 看到公告，也會收到私訊。

## 怎麼填

1. 打 **`/管理可配合時間`**，選月份
2. **勾日期 → 設時段**。同一個時段可以一次勾很多天
3. 不同時段就「繼續選日期」再加一組
4. 全部填完按「**檢查全部時段**」
5. 確認沒問題按「**全部確認送出**」

> **按「全部確認送出」之前都不會真的存檔。** 中途取消、關掉視窗都不影響，下次打開還在。

## 「檢查全部時段」會告訴你什麼

系統會比對你已經排定的任務，然後列出**實際會保留的時段**：

- 跟已排定任務衝突的部分 → 自動排除
- 整段都被佔用的 → 會要你回去改
- 重複或重疊的時段 → 自動合併

所以你看到的清單跟你填的可能不一樣，那是正常的。

**只有已經正式通知你的任務會被排除。** 公司還在安排、還沒通知你的，不會出現在這裡——你照自己真正有空的時間填就好，撞到的話公司會再跟你確認。

## 填完之後可以改

打開 `/管理可配合時間` 選月份，可以：

- **修改單日** — 只改某一天，同組其他日期不受影響
- **修改整組** — 整組改時段
- **移除** — 刪掉整組
- **新增／補填日期** — 再加新的

送出前的草稿隨時能改；已經送出的也能刪掉重填，**不用找公司重發公告**。

## 系統存了什麼

送出後每一筆會記在 Notion 的可用時段表：日期時間、你的名字、送出時間、是否逾期、還有你填的備註。
