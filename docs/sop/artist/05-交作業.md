# 交作業

## 什麼時候可以交

有些任務會分兩次通知：

1. 第一次 —「你有這件事」
2. 第二次 —「📚 課後作業通知」← **收到這個才代表可以交**

看到第二次通知，或在 `/我的任務` 看到「提交任務」按鈕，就是開放了。

## 怎麼交

1. 到 `任務查詢入口` 打 **`/我的任務`**
2. 點「**提交任務（N）**」
3. 畫面會列出可以交的任務與要求 → 選你要交的那筆
4. 系統給你一個專屬的公司 Drive 資料夾連結 → 把檔案上傳進去 → 按「**我已上傳到 Drive**」
   > 💡 這則訊息**只有你看得到**，切去 Drive 上傳再回來時可能已經消失。**沒關係**：重新打 `/我的任務` → 提交任務 → 選**同一筆**任務，會回到同一個資料夾，剛剛上傳的檔案都還在，直接按「我已上傳到 Drive」就好。（3 小時內有效）
5. 送出後任務變「待審核」，等結果通知

**所有任務都是這一種交法**：上傳到公司 Drive。不再收貼雲端連結或打字回報；文字類的內容（例如企劃想法）請存成檔案（Word、PDF、文字檔都可以）再上傳。

> ⚠️ **檔案不要傳到 Discord**，系統不收 Discord 附件。一律上傳到系統給你的 Drive 資料夾，那個資料夾只分享給你一個人，別人看不到。

## 交出去之後

**不能自己撤回。** 內容有錯直接跟公司或老師說，等審核回來會有機會重交。

## 審核結果

| 結果 | 會怎樣 |
|---|---|
| **通過** | 任務完成 |
| **需修改** | 給你 1～7 天修改期限，改完重交。修好之前每天早上的任務提醒會列在「🛠 需修改」 |
| **退回** | 同上 |

你會收到**一到兩則**私訊：

1. **審核結果**（審核一送出就到）：通過、需修改或退回，加上審核人的文字回饋。需修改與退回會寫明修改期限。
2. **批改檔**（有的話才有，晚一點到）：標題是「📎 老師補充了批改檔」，裡面是 Drive 連結，點進去就能看老師批改過的檔案。

沒有看到第二則不代表有問題，是老師這次沒有附批改檔。批改檔放在只有你和公司看得到的資料夾。

重交之後狀態回到「待審核」，等下一輪結果。
