# 每天早上的任務提醒

每天早上 9:00，系統會私訊你**一則**「今天的任務提醒」，把需要你注意的任務全部列在一起。沒有要注意的任務那天就不會發。

```discord
☀️ 10/21（三）今天的任務提醒

🔴 已逾期（1）
・10/20（二）開圈影片｜截止 10/20（已過 1 天）

⏳ 已過截止，等公司確認（1）
・10/20（二）發布：吃宵夜 POV｜截止 10/20（已過 1 天）
還沒做完請盡快完成；已經做完不用理會，公司會確認。

⏰ 快到期（1）
・11/6（五）編曲課作業 編曲仿作-Tom Misch｜截止 10/28（剩 7 天）

想看某一筆的內容，用下方選單；看完按「👌 我都看到了」。要交件請用 /我的任務。
[看某一筆的詳細…▾] [👌 我都看到了]
```

## 會列哪些任務

| 區塊 | 什麼時候出現 | 怎麼處理 |
|---|---|---|
| 🔴 已逾期 | 要交件的任務過了期限還沒交，或控方確認你真的沒做 | 盡快交件，或跟控方說明 |
| 🛠 需修改 | 審核退回，等你修改重交 | 照回饋修改，在修改期限內重交 |
| ⏳ 已過截止，等公司確認 | 不用交件的任務（發文、出席這類）過了期限 | 做完了**不用理會**；還沒做完請盡快完成並跟控方說 |
| ⏰ 快到期 | 只在期限前 5 天、3 天（或控方另外勾的時間點）出現，中間幾天不會一直出現 | 照計畫進行 |
| 📌 還沒按收到 | 你還沒按「收到任務」的任務 | 回到那張任務卡按「收到任務」 |

## 怎麼用

1. 想看某一筆的內容：用訊息下方的「**看某一筆的詳細**」選單。內容會展開在**同一則訊息**下面，再選別筆就換成那一筆，不會多跳訊息。
2. 看完按「**👌 我都看到了**」，這則就收成一行「✅ 已讀」。控方會知道你看過了。

- 一天只有**一則**，隔天新的來時，前一天的會自動消失。
- **已逾期、需修改**的任務，按了「我都看到了」之後隔天還是會列出來（標「⚠️ 仍未完成」），直到你交件或控方處理好。

> 💡 按一次「我都看到了」會把整則的任務都記成看過。某一筆有疑問，直接問控方或小律。
