# 每天早上的任務提醒

每天早上 9:00，系統會私訊你**一則**「今天的任務提醒」，把需要你注意的任務全部列在一起。沒有要注意的任務那天就不會發。

```discord
☀️ 10/21（三）今天的任務提醒

🔴 已逾期（1）
・10/20（二）開圈影片｜截止 10/20（已過 1 天）

⏳ 已過截止，等公司確認（1）
・10/20（二）發布：吃宵夜 POV｜截止 10/20（已過 1 天）
還沒做完請盡快完成；已經做完不用理會，公司會確認。

⏰ 快到期（1）
・11/6（五）編曲課作業 編曲仿作-Tom Misch｜截止 10/28（剩 7 天）

想看某一筆的內容，用下方選單；看完按「👌 我都看到了」。要交件請用 /我的任務。
[看某一筆的詳細…▾] [👌 我都看到了]
```

## 會列哪些任務

| 區塊 | 什麼時候出現 | 怎麼處理 |
|---|---|---|
| 🔴 已逾期 | 要交件的任務過了期限還沒交，或公司確認你真的沒做 | 盡快交件，或跟公司說明 |
| 🛠 需修改 | 審核退回，等你修改重交 | 照回饋修改，在修改期限內重交 |
| ⏳ 已過截止，等公司確認 | 不用交件的任務（發文、出席這類）過了期限 | 做完了**不用理會**；還沒做完請盡快完成並跟公司說 |
| ⏰ 快到期 | 只在期限前 5 天、3 天（或公司另外勾的時間點）出現，中間幾天不會一直出現 | 照計畫進行 |

## 怎麼用

1. 想看某一筆的內容：用訊息下方的「**看某一筆的詳細**」選單。內容會展開在**同一則訊息**下面，再選別筆就換成那一筆，不會多跳訊息。展開時下面多一顆「**⚠️ 這筆有問題**」，這筆不行就直接按它回報。回報後早報上那一行會標「⚠️ 已回報」。其他筆如果也有問題，一樣展開後回報；都看過了再自己按「👌 我都看到了」，回報過的那幾筆不會被記成看過。早報裡每一筆都回報了，就直接算已讀。
2. 看完按「**👌 我都看到了**」，這則就收成一行「✅ 已讀」。公司會知道你看過了。

- 一天只有**一則**，隔天新的來時，前一天的會自動消失。
- **有還沒收到的任務時，這則會先請你確認**（2026-10-23 起）：一開始只顯示「📌 先確認：還沒收到的任務（N）」，底下只有「✅ 全部收到」和「⚠️ 某一筆有問題」。處理完，**同一則**才換成今天的提醒和「👌 我都看到了」，最上面會寫你剛剛收到或回報了幾筆。
- 早上發這則時，前幾天已經處理完的通知（收成一行的「已收到」「已回報」）會一起清掉，私訊裡只留今天要看的。
- 「👌 我都看到了」只代表看過提醒，跟收到任務無關；收到一律在「全部收到」或任務卡的「收到任務」按。
- **已逾期、需修改**的任務，按了「我都看到了」之後隔天還是會列出來（標「⚠️ 仍未完成」），直到你交件或公司處理好。

> 💡 按一次「我都看到了」會把整則的任務都記成看過（回報過問題的那幾筆除外）。「看到了」只代表你讀過，不代表每一筆都沒問題；某一筆不行，請先用「這筆有問題」回報，或直接問公司、小律。
