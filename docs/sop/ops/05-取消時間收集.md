# 取消時間收集

> 💡 **誰可以做**：有 `控方` 身分組的人。

## 步驟

1. 到 `營運操作` 打 **`/取消時間蒐集`**。
2. 從 **選擇要取消的收集…** 選要取消的那一筆。每一筆會寫月份、截止時間、已填幾位。
3. 按 **🛑 確認取消收集**。不想取消就按 **✖️ 取消**。
4. 看到「🛑 已取消 2026-11 的時段收集」就完成了。

## 接下來會發生什麼

- 不會再催藝人填，也不會再有排課時效提醒
- **藝人已經填的時段會保留**，之後排課照樣用得到
- **已經發出去的公告和私訊收不回來**

## 你下一步

1. 到 `公告區` 刪掉那則公告。
2. 在群組跟藝人說一聲。
3. 需要的話，用「發起每月時間收集」重新發一次。

> 💡 全部填完、或已經過了截止的收集，系統會自己結束，不用取消。
