# 任務內頁怎麼寫

總表的 `任務說明` 欄位**已廢除**。藝人、同仁看到的任務內容，一律是**點進任務後的內頁整頁**。

**怎麼寫**

1. 點進任務，直接在內頁寫。**不用加標題**；有 `## 任務說明` 標題也可以（時間池建的任務會自動加），只是當記號。
2. 寫清楚**做什麼、做多少、用什麼形式交、什麼時候交**，例如「聽力訓練：50 題音程／截圖」。藝人沒有別的地方可以查，小律回答細節也只看這一頁。
3. 時間要改 `開始日`／`截止日` 欄位；內頁裡寫的時間不會被系統當成正式時間。

**會被讀到的**：一般段落、標題、條列、待辦、引用、callout、切換清單裡面、分欄裡面、表格（每列變成「欄｜欄」）、書籤／嵌入的網址。巢狀最多讀 3 層。

**不會被讀到的**
- **子頁面、連結的資料庫**：要放不想給藝人看的東西，就放子頁面。
- **圖片、檔案、PDF**：藝人收不到附件。要給檔案，請放 Drive 連結（網址會保留）。
- 系統自己寫的兩段：**「藝人回覆」**（藝人按「有問題」時寫入）、**「Drive 資料夾索引」**（多人任務首次交件時寫入）。

**⚠️ 要注意的事**

| 注意 | 為什麼 |
|---|---|
| **整頁都會被藝人看到** | 派發通知、截止前提醒、藝人／同仁早報、小律念的都是這一頁。內部備註、報價、參考文章、其他藝人的資訊**不要放在內頁**，放子頁面 |
| **Notion 網址會被拿掉** | 藝人端零 Notion 入口（M7-04），內頁貼的 Notion 連結藝人看不到；Drive、YouTube 等其他網址保留 |
| **`名稱：` 開頭的行會被濾掉** | `安排來源：`、`課程類別：`、`負責老師：`、`需要時長：`、`候選時段`… 這類行首字樣是時間池寫的控方欄位，藝人看不到。要交代就寫成一句話（「這週改由 B 老師上課」） |
| **太長會被截斷** | 派發通知最多約 900 字、截止前提醒 700 字、交件清單 120 字摘要、小律與「看詳細」1,500 字。重點寫在最前面 |
| **已發出的通知不會自己更新** | 改了內頁，已經送出的私訊還是舊內容；要藝人看到新版，用 `/任務通知重送` 或勾 `重送通知`。早報、小律下次讀就是新的 |
| **不要改系統段落的標題** | 「藝人回覆」「Drive 資料夾索引」改名的話，系統會把它當成任務內容念給藝人 |
| **讀不到內頁時顯示「尚未填寫」** | Notion 暫時出錯時，那一輪通知會寫「Notion 尚未填寫任務說明」。內頁確定有寫卻出現這句，等下一輪或重送 |
| **內頁空白** | 藝人只會收到「Notion 尚未填寫任務說明」，派發前先確認 |

**欄位廢除的順序（一次性，2026-10-21）**：① 舊欄位內容搬進內頁（已完成：94 筆）→ ② 重開 bot → ③ 控方從 Notion 刪 `任務說明` 欄位。**順序不能反**：先刪欄位、舊程式還在跑的話，舊欄位那批任務的說明會變空白。

## ⚠️ 課程任務一定要自己補一段

`/時間交集查詢` 建出來的課程任務，任務內頁會長這樣（Bot 會自動加 `## 任務說明` 標題）：

```notion
安排來源：/從時間池建立任務
課程類別：舞蹈課
負責老師：lurasupa
需要時長：2 小時
候選時段（由營運最後確認）：
2026-09-17 19:30~21:30
```

**這些全部是給你看的，藝人一行都看不到。** 系統會自動濾掉 `安排來源：`、`課程類別：`、`負責老師：`、`需要時長：`、`候選時段` 這類控方內部欄位，所以濾完是空的，藝人收到的就是「Notion 尚未填寫任務說明」。

**做法**：在這段文字下面**另起一行**寫給藝人的內容，例如：

```notion
（上面 Bot 產生的內容不用動）

這週練上次那支編舞的後半段，記得帶練習服。
```

你加的這行不會被濾掉，會原樣出現在藝人的通知裡。兩者可以共存，不必刪掉 Bot 產生的部分。

> **寫的時候避開 `名稱：` 這種格式開頭**。過濾是比對行首關鍵字，你若寫成「負責老師：換成 B 老師」也會被當成內部欄位濾掉。要交代這類事情就寫成一句話，例如「這週改由 B 老師上課」。
