# 派發作業（兩階段）

**不要建兩筆任務。** 同一筆 Task 用 `是否開放提交` 切成兩段：

```text
第一階段  勾 Discord 顯示、不勾 是否開放提交
          → 藝人收到「你有這件事」通知

          （上完課 / 任務進行中）

第二階段  回到同一筆 Task 補上：
          任務說明（作業要求）、提交期限、審核人員
          → 勾 是否開放提交
          → 藝人收到「📚 課後作業通知」
```

第二次通知最晚 30 分鐘內發出，**每筆任務只發一次**，不會重複轟炸。

沒收到的話依序檢查：`Discord 顯示` 有勾嗎？有關聯藝人嗎？藝人 Notion 有填 Discord User ID 嗎？
