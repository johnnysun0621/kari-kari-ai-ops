# 時間與期限一覽

## 每天固定時間

| 時間 | 發生什麼 |
|---|---|
| 09:00 | 藝人早報、同仁早報（私訊） |
| 09:30 | 營運早報（`營運內部通知`），前一天的自動刪掉 |
| 10:00 | 審核人員收到待審核提醒；課後提醒老師；Drive 健康檢查 |
| 每週一 09:30 | 營運早報多一區「發文待確認發布」 |
| 每 30 分鐘 | 派發、課後作業通知、逾期判斷、批次重送 |
| 每 5 分鐘 | 布告欄同步、本月排程更新 |

這些時間要改請找工程端。

## 每次操作時決定的

| 項目 | 預設 | 在哪決定 |
|---|---|---|
| 月度收集截止 | 1 天（24 小時）| 打 `/時間資訊蒐集` 時填 `截止天數` |
| 修改期限 | 無預設 | 審核退回時當場選 **1～7 天** |
| 任務截止前提醒 | 5 天前＋3 天前 | 每筆任務的 `提醒規則` 欄位只能再加 |
| 提前交件任務提前交件 | 5 天 | 逐筆填 `提交期限` 就以它為準；預設天數要改請找工程端 |

## 操作畫面的逾時

按鈕與選單放著不動會失效，重打指令即可，**不會遺失已送出的資料**。

| 畫面 | 逾時 |
|---|---|
| 一般選單、任務清單、審核清單 | 10 分鐘 |
| 審核動作、批改檔選擇、伺服器初始化 | 5 分鐘 |
| 任務重送確認 | 3 分鐘 |
| 等待藝人上傳檔案 | 3 小時 |
| 小律回答下方的「回報問題」 | 24 小時 |
