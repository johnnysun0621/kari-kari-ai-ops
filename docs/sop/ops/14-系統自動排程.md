# 系統會自己做的事

背景每 **30 分鐘**檢查一次，所以任何自動通知**最晚會在 30 分鐘內送出**。

> 💡 **每天一次的發送送不到會自動重試**（2026-10-21 起）：藝人／同仁早報（09:00）、營運早報（09:30）、審核人員催辦（10:00）如果有人送失敗，或系統讀 Notion 失敗，30 分鐘後自動再試，同一天最多 3 次。已經收到的人不會重複收到。第 3 次還送不到的審核人員提醒，會改發到 `營運內部通知`（營運早報關掉時）。

| 項目 | 觸發條件 | 時間規則 |
|---|---|---|
| **任務派發** | 勾 `Discord 顯示`、有關聯藝人或相關同仁、未結案 | 下一輪輪詢（≤30 分）。同一位藝人這一輪 2 筆以上合併成一則（M3-27） |
| **課後作業通知** | 再勾 `是否開放提交` | 下一輪輪詢（≤30 分），每筆只發一次。同一位藝人這一輪 2 筆以上合併成一則 |
| **每日早報**（M3-24；M3-30 起開頭和結尾一句由小律依每位藝人當天狀況寫，失敗時用固定範本句） | 每位藝人有已逾期、需修改、已過截止等確認、快到期的任務 | **每天 09:00 一則**，取代逐則私訊。藝人用選單看細節、按「👌 我看完了」；每筆任務的 `提醒確認` 會記「早報｜時間｜已發送給 N 人」和「早報｜時間｜藝人」。隔天發新的時刪掉前一天的。已逾期、需修改確認過後隔天仍列，標「⚠️ 仍未完成」。要回到逐則通知請找工程端 |
| **沒按收到** | 藝人沒按「收到任務」 | 每天 09:00 那一則**先只問還沒收到的任務**（全部收到／哪一筆不行？），處理完那則收起來，提醒和「我看完了」以新的一則出現在最下面（原地換的話按鈕會被推到畫面外），避免藝人以為按「我看完了」就算收到（M3-29）。同時清掉這位藝人之前已處理完的任務通知。超過 3 天也列在營運早報 |
| **截止前提醒** | 預設＋`提醒規則` | 一律**死線前 5 天、3 天**，勾的再加。到期的階段**排進當天早上的早報**，不再一則一則私訊藝人；相關同仁改收每天一則同仁早報（跟藝人早報同時發）。提前交件任務的死線＝交件日（截止日 − 5） |
| **逾期升級** | **要交件的任務**（有勾 `是否開放提交`）過了死線 | 狀態改 `已逾期`，**隔天營運早報列在「新逾期」**；藝人在他的早報看到。你改回 `進行中` 但沒延期的話，下一輪會再改回 `已逾期` |
| **已過截止，等你確認**（M2-14） | **不用交件的任務**（沒勾 `是否開放提交`，例如發文、出席、提大綱）過了死線、你還沒結案 | **狀態不會被改成 `已逾期`**，維持原樣。藝人早報列「⏳ 已過截止，等公司確認」（附「還沒做完請盡快完成；已經做完不用理會」），營運早報列「⏳ 已過截止，等你確認結案」。見「不用交件的任務過了截止」 |
| **每日催辦** | `待審核` 滿 24 小時 | **每天 10:00**，審核人員每人一則（最後附「怎麼審」），沒填或聯絡不到就發到 `營運內部通知`。藝人端的已逾期、需修改已併進早報 |
| **修改期限逾時** | 過了 `修改期限` 還停在 `需修改` | 營運早報的「修改期限已過」每天列出，直到藝人重交或你改期限 |
| **課後提醒老師** | 專案類型 `課程培訓`、課程結束（`截止日`）滿 2 小時、還沒結案 | 私訊負責老師到論壇發布作業要求與評語，之後每天 10:00 一次，最多 7 天；仍未結案改在營運早報列一次。**同一位老師這一輪有好幾堂課，只收一則**。老師沒有 Discord ID 就列在營運早報請你轉告。**營運需手動到論壇確認老師已發布，再把任務改成 `已完成`；Bot 不會自動偵測論壇貼文。** |
| **發文待確認發布** | 發文類任務停在 `已完成`、截止日過 3 天 | **每週一的營運早報**多一區清單，提醒你確認發布後改成 `已完成發文` |
| **批次重送** | Tasks 勾了 `重送通知` | 下一輪輪詢（≤30 分），重送後自動取消勾選。每一輪排在任務派發前面：同一筆同時勾了 `Discord 顯示` 和 `重送通知` 只送一次 |
| **本月排程公告** | 自動 | 跟布告欄同步一起，**每 5 分鐘**，有變才更新 |
| **月度時間池催填** | 收集期未填完 | 藝人在**截止前 6 小時**、**逾期後**各收一次私訊；你在營運早報看「已填幾位、還沒填誰」，不再每位藝人填完就跳一則 |
| **月度時間池收齊** | 全員填完 | 立即通知營運，並停止該次收集的檢查 |
| **排課 SLA** | 流程拖太久 | **48 小時**升級通知、**72 小時**提示候選可能失效 |
| **Notion 選項檢查** | bot 每次啟動 | 比對程式拿來篩選的選項（任務狀態、審核狀態、身份類型、會議類型…）在 Notion 還在不在。對不上就在 `營運內部通知` 發一則「⚠️ Notion 選項和程式對不上」，列出少了哪個選項、哪個功能會壞。**通常是有人刪掉或改名了選項，改回原名即可** |
| **Drive 健康檢查** | 自動 | **每天 10:00** 讀一次 Drive 總資料夾。正常不出聲；失敗時在 `營運內部通知` 發一則「⚙️ 系統警告｜Google Drive…」，附原因與修法（一天最多一則）；恢復時同一則改成 🟢 系統恢復。**看到要當天處理，否則藝人交不了件** |
| **布告欄同步** | 自動 | **每 5 分鐘** |

> 💡 **月度時間收集只催兩次**，這是刻意設計避免騷擾藝人。收集期設得長（例如 3 天）的話，中間會有很長一段完全不提醒，需要的話請自行在群組補提醒。

所有重要動作都會寫 `Audit Log`（事件名稱、操作類型、來源系統、操作者、前值後值、目標頁面、結果）。
