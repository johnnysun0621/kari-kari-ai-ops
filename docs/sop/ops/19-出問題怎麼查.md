# 出問題怎麼查

| 狀況 | 檢查順序 |
|---|---|
| **藝人沒收到通知** | ① `Discord 顯示` 有勾？② 有 `關聯藝人`？③ 藝人 Notion 有填 `Discord User ID`？④ 都有的話打 `/任務通知重送` |
| **同仁沒收到通知** | ① 任務的 `相關同仁` 有填？② People 有填 `Discord User ID`？**沒填 ID 的同仁一定收不到，系統不會另外通知你**（營運早報也不會提醒）③ `Discord 顯示` 有勾？④ 同仁早報只列已逾期、需修改、快到期的任務，沒有這三種就不會發 |
| **老師沒收到課後提醒** | ① 任務的專案類型是 `課程培訓`？② `負責老師` 有填？③ 老師在 People 有 `Discord User ID`？沒有的話會列在營運早報的「老師的課後作業」 |
| **通知發出去了但內容不對** | 先在 Notion 改好欄位（時間要改 `開始日`／`截止日`，不是只改說明文字），再用 `/任務通知重送` |
| **通知寫「尚未填寫任務說明」但內頁有寫** | ① 內容是不是在子頁面裡？（子頁面不讀）② 是不是只有圖片／檔案？（附件不讀）③ 是不是整段都是 `名稱：` 開頭的行？（會被濾掉）④ 都不是的話，可能是 Notion 那一輪讀取失敗，用 `/任務通知重送` |
| **藝人看到不該看的內容** | 內頁整頁都會傳給藝人。把那段移到子頁面，再 `/任務通知重送`；已送出的私訊無法收回 |
| **通知訊息沒有時間** | Task 的 `開始日`／`截止日` 是空的。補上後重送 |
| **重送後藝人說又要再按一次確認** | 正常。重送會清空確認紀錄，內容變了本來就該重新確認 |
| **藝人說看不到 `/我的任務`** | 他在錯的頻道打，只能在 `任務查詢入口` |
| **可排課藝人 0 位** | Artists 有填 `Discord User ID`？`合約狀態` 是不是 `暫停`／`封存`？都對的話請工程端確認 Notion 權限 |
| **比對不到共同空檔** | 月份選錯？有人沒填？時長太長？既有任務佔滿了？ |
| **勾了開放提交但沒通知** | 等一輪輪詢（最多 30 分鐘）；再確認 `Discord 顯示` 也有勾 |
| **審核寫入失敗** | 確認 Submissions 有這四個欄位：`審核回饋`、`審核者`、`審核來源`、`審核通知時間` |
| **管理指令看不到** | 帳號有 Discord 管理員權限嗎？Bot 在線嗎？都正常的話請工程端重開 bot |
| **藝人填錯時間** | 請他自己用 `/管理可配合時間` 刪除重填 |

查不出來時，看 Notion 的 `Audit Log`，裡面有每個動作的成功／失敗紀錄與錯誤訊息。畫面上出現「❌ …失敗，請稍後再試」而 Audit Log 也看不出原因的，把那句話和時間給工程端查 bot 記錄檔。
