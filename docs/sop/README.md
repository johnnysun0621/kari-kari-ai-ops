# SOP 怎麼寫

SOP 分三個版本，一頁一篇，照讀者的需要寫。網站與完整版都由這些分頁自動產生。

| 資料夾 | 給誰看 | 怎麼寫 | 網站 |
|---|---|---|---|
| `artist/` | 藝人 | 「我想…」：在哪按什麼、會看到什麼。不出現 Notion 欄位名稱 | 藝人版、營運版、工程版 |
| `ops/` | 營運、審核人、老師 | 「我想…」：打開哪裡、點什麼、填什麼、誰會收到什麼、你下一步 | 營運版、工程版 |
| `eng/` | 工程師 | 參考資料：觸發條件、程式進入點、讀寫哪些欄位、去重、已知限制 | 工程版 |

寫法參考 Notion、Slack 的說明中心（一篇一件事、一步一個動作），以及 Diátaxis 文件框架：藝人版、營運版是「怎麼做」，工程版是「查資料」，不要混在一起。

## 完整版是產生出來的

`ADMIN_SOP.md`、`ARTIST_SOP.md`、`ENGINEERING_SOP.md` 由分頁合併產生，**不要直接改**。改完分頁執行：

```text
.venv/Scripts/python.exe scripts/build_sop.py
.venv/Scripts/python.exe scripts/build_sop_site.py
```

測試會檢查：
- 完整版跟分頁一致（`tests/test_sop_pages.py`）
- 藝人版、營運版沒有工程用語
- **程式裡每一個按鈕、選單、填寫視窗、指令，都寫進藝人版或營運版的某一篇**（`tests/test_sop_coverage.py`）。新增按鈕卻沒寫 SOP，測試會失敗

## 每頁開頭的標記

```yaml
---
title: 派一筆要交作業的任務          # 頁面標題，也是網站選單上的名字；動詞開頭
audience: ops                       # artist、ops 或 eng，要跟資料夾一致
order: 9                            # 同一個資料夾裡的順序，不能重複
section: 任務                        # 選填：網站選單上的分組小標題
rules: [M2-15, M4-19]               # 對應 Notion 規則頁的編號，沒有就寫 []
summary: 一句話說這頁講什麼          # 網站卡片、完整版目錄用
updated: 2026-10-26                 # 最後一次改內容的日期
---
```

標記下面第一行是 `# 標題`，跟 `title` 一樣。頁內小節用 `##`。

## 藝人版、營運版的固定版型

1. **標題**：動詞開頭，例如「審核一份作業」
2. **誰可以做、大約要多久**（放在 `> 💡` 提示框）
3. **示意圖**：能畫就畫
4. **開始前**：要先準備好什麼（勾選清單）
5. **步驟**：編號，一步一個動作；要按的按鈕、要選的選單用粗體，文字照畫面原文
6. **接下來會發生什麼**：誰在多久內收到什麼，訊息照原文
7. **你下一步**：連到下一篇
8. **常見問題**：`| 狀況 | 怎麼做 |`

營運版只寫操作時要找的 Notion 欄位，系統背後寫了哪些欄位放工程版。藝人版不寫欄位名稱。

## 固定寫法（網站會變成互動元件）

| 寫法 | 用在哪 | 網站上會變成 |
|---|---|---|
| `> ⚠️ …` | 會出事、不能做的事 | 警告框 |
| `> 💡 …` | 小提醒、誰可以做 | 提示框 |
| `> ⏸ …` | 封存中、暫停的功能 | 灰色封存標示 |
| `- [ ]` 勾選清單 | 開始前的檢查 | 可勾選（記在該裝置） |
| `<details><summary>問題</summary>答案</details>` | 常見問題 | 點開才看到的段落 |
| ```` ```discord ```` | Discord 訊息、按鈕的樣子 | Discord 樣式的示意畫面 |
| ```` ```notion ```` | Notion 內頁會出現的文字 | Notion 樣式的示意 |
| ```` ```text ```` | 資料夾路徑 | 等寬文字 |
| ```` ```mermaid ```` | 示意圖：流程（`flowchart`）、誰對誰做了什麼（`sequenceDiagram`）、狀態怎麼變（`stateDiagram-v2`） | 畫成圖，顏色跟著深淺色 |

## 其他原則

- 頁與頁之間用「見『頁面標題』」互相指，網站會自動變成連結。不要寫「見上一節」
- Discord 範例用真實的格式，訊息標題照程式原文
- 工程端的設定、`.env`、記錄檔放在 [`docs/operations/SETTINGS.md`](../operations/SETTINGS.md) 或工程版
