# 控方操作 SOP

LURASUPA 營運系統的完整操作手冊。照實際工作順序編排，每個流程都標明**系統會在 Notion 寫什麼**，這樣出狀況時你知道去哪裡看。

---

## 開始之前

**指令一律在 `營運操作` 頻道打。** 在別的頻道會被擋下來並提示你換頻道。

看不到管理指令的話：確認你的 Discord 帳號有管理員權限、Bot 在線。

六個頻道各自的用途：

| 頻道 | 誰用 | 做什麼 |
|---|---|---|
| `營運操作` | 控方 | 打所有管理指令 |
| `營運內部通知` | 控方 | 接收系統通知，不用打指令 |
| `公告區` | 全體（唯讀）| 公開任務與收集公告 |
| `時間管理` | 藝人 | 回報可配合時間 |
| `任務查詢入口` | 藝人 | 查任務、交作業 |
| `課程助教` | 藝人 | 問小律 |

## 流程一：每月收集可配合時間

### 你要做的

在 `營運操作` 打 **`/時間資訊蒐集`**：

| 參數 | 填什麼 |
|---|---|
| `月份` | `2026-10` |
| `截止天數` | 預設 1（24 小時內回填）|
| `說明` | 選填，例如「請優先填週末」|

### 系統會做的

1. 讀 `Artists`，找出所有可排課藝人（有 Discord User ID、合約狀態為 `已簽約` 或 `洽談中`）
2. 在 `公告區` 發公告並 mention 這些藝人
3. 私訊每一位藝人
4. 寫一筆 `Audit Log`

### 藝人填完後

系統把每一筆寫進 **`Availability Slots`**：

> `可用時段名稱`、`填寫藝人`、`填寫人名稱`、`身份`=藝人、`來源`=Discord、`可用開始時間`、`可用結束時間`、`提交時間`、`是否逾期提交`、`備註`（收集月份與藝人備註寫在這）

全員填完，系統會通知你可以開始排課。

### 有人沒填

請他自己打 `/管理可配合時間` 補，**不用重發公告**。系統也會自動催他。

## 流程二：排課

### 只想看看有沒有空檔

**`/時間交集查詢`** — 唯讀，**完全不會寫入 Notion**。

選月份、需要的時長、勾要比對的藝人 → 看共同空檔。

看完想排的話按「直接建立任務」就接到下面的流程；不想排就按「關閉」。

候選時段多的時候會分頁，用「上一頁／下一頁」看完。

### 要直接排

**`/從時間池建立任務`** — 參數一樣（月份、時長分鐘）。

跟上面的差別：這支會**先自動整理藝人的時間池**（合併重疊、封存重複），所以比對用的是最乾淨的資料。整理動作會更新 `Availability Slots` 並寫 `Audit Log`。

### 選完候選時段之後

系統讓你選任務類型（選項直接從 Notion 的 `任務類型` 讀出來，Notion 加新選項這裡就會有）。

**選「課程與作業」** → 再依序選課程類別、課程培訓 Project、負責老師，最後填課程名稱。

**選其他類型** → 再選精準時間，填地點等資訊。

每一層都可以「返回上一步」，Modal 取消也不會寫入任何東西。**只有走到最後才會真的建立。**

### 系統建立的東西

在 **`Tasks`** 建一筆：

| 欄位 | 寫入值 |
|---|---|
| `任務名稱` | 你填的 |
| `任務狀態` | `尚未開始` |
| `任務類型` | 你選的 |
| `關聯藝人` | 你勾的藝人 |
| `任務說明` | 候選時段等資訊 |
| `是否開放提交` | `false` |
| **`Discord 顯示`** | **`false`** |
| `課程類別`／`負責老師`／`關聯專案` | 課程流程才有 |
| `開始日`／`截止日` | 有選精準時間才有 |

> **重點：建立當下 `Discord 顯示=false`，所以藝人不會收到任何通知。** 這是草稿，等你補完內容再開。

回覆訊息會附上那筆 Notion Task 的連結，直接點進去編輯。

## 流程三：在 Notion 完成任務設定

不論是系統建的草稿，還是你自己在 Notion 開的任務，欄位規則都一樣。

### 一定要填

| 欄位 | 為什麼 |
|---|---|
| `任務名稱` | 藝人看到的標題 |
| `任務類型` | 決定要不要佔用藝人時段、要不要發公告區 |
| `關聯藝人` | **沒填就沒有人會收到通知** |
| `截止日` | 提醒與逾期判斷的依據 |

### 控制系統行為的兩個開關

| 欄位 | 勾了會怎樣 |
|---|---|
| **`Discord 顯示`** | 藝人收到私訊通知，並出現在他的 `/我的任務`。**沒勾＝完全不通知** |
| **`是否開放提交`** | 藝人可以交件。**任何任務類型都適用**，不是只有課程 |

### 要交件才填

| 欄位 | 說明 |
|---|---|
| `提交方式` | `檔案`／`Drive 連結`／`文字`／`混合` |
| `提交期限` | 作業什麼時候交。**不要改 `截止日`**，那是正式行程時間 |
| `審核人員` | 指定誰審；不填就由控方審 |

### 選填

| 欄位 | 說明 |
|---|---|
| `提醒規則` | **不勾＝截止前 5 天自動提醒**。要改就勾（5 天前／3 天前／1 天前／當天，可複選）|
| `負責老師`／`課程類別` | 課程任務用 |
| `關聯專案` | 有上層企劃時填 |

> **提醒規則的隱藏用法**：只勾「逾期」＝事前都不要提醒，逾期再通知。這是關閉事前提醒的唯一方式。

### 公開類型

`任務類型` 是 **`通告`** 或 **`演出`** 時，除了私訊藝人還會發到公告區，全體看得到。其他類型只私訊關聯藝人。

### 勾下 `Discord 顯示` 之後

系統在下一輪背景檢查（最多 30 分鐘）會：

1. 私訊每位關聯藝人：任務名稱、類型、截止日、提交方式
2. 附三顆按鈕：**收到任務** / **有問題・無法配合** / **查看任務內容**
3. 在 Task 寫入 `Discord 通知時間`
4. 公開類型另外發到 `公告區`

**藝人按「收到任務」** → 系統寫 `Discord 收到時間`，`任務狀態` 變 `進行中`。

**藝人按「有問題・無法配合」** → 他填的原因會**追加到 `任務說明`**（不覆蓋原內容），任務退回 `尚未開始`、`Discord 顯示` 自動取消、通知時間清空，並通知 `營運內部通知`。你改完重新勾 `Discord 顯示` 就會重新派發。

**沒按確認** → 系統每 12 小時重送一次，直到他按為止。

## 流程四：派發作業（兩階段）

**不要建兩筆任務。** 同一筆 Task 用 `是否開放提交` 切成兩段：

```
第一階段  勾 Discord 顯示、不勾 是否開放提交
          → 藝人收到「你有這件事」通知

          （上完課 / 任務進行中）

第二階段  回到同一筆 Task 補上：
          任務說明（作業要求）、提交方式、提交期限、審核人員
          → 勾 是否開放提交
          → 藝人收到「📚 課後作業通知」
```

第二次通知最晚 30 分鐘內發出，**每筆任務只發一次**，不會重複轟炸。

沒收到的話依序檢查：`Discord 顯示` 有勾嗎？有關聯藝人嗎？藝人 Notion 有填 Discord User ID 嗎？

## 流程五：收件與審核

### 藝人交件時系統做的事

在 **`Submissions & File Index`** 建一筆：

> `提交名稱`、`提交藝人`、`關聯任務`、`提交來源`=Discord、`提交類型`、`檔案類型`（依任務類型自動對應）、`審核狀態`=待審核、`權限等級`=藝人本人、`是否最新版`=true、`提交時間`
> 交檔案的話另外寫 `Drive URL`、`Drive File ID`、`原始檔名`、`檔案大小 MB`；純文字寫在 `備註`

同時：
- 同一任務的舊提交自動取消 `是否最新版`（永遠只有一筆最新）
- Task 的 `任務狀態` 變 `待審核`、`最新提交 URL` 回寫
- 你在 `營運內部通知` 收到提醒

### 你要做的

在 `營運操作` 打 **`/審核提交`**：

1. 選一筆待審核的
2. 系統列出 Drive 連結、文字內容、關聯任務，**先看過再判斷**
3. 選 `通過`／`需修改`／`退回`
4. 填給藝人的回饋（可留空）
5. 選需修改或退回時，要填 **1～7 天的修改期限**
6. 老師有批改檔按「附批改檔」，沒有按「不需補批改檔」

### 系統寫回

| 動作 | 寫入 |
|---|---|
| 審核完成 | Submissions 的 `審核狀態`、`審核回饋`、`審核者`、`審核來源` |
| 通知藝人後 | `審核通知時間` |
| 通過 | Task `任務狀態` → `已完成` |
| 需修改／退回 | Task `任務狀態` → `需修改`、寫入 `修改期限` |

藝人重交後，系統清除本輪 `修改期限`，狀態轉回 `待審核`。

### 也可以在 Notion 直接審

改 `審核狀態`，然後**至少填 `審核回饋`、`審核者`、`審核來源` 其中一個**。系統背景偵測到才會通知藝人。只改狀態不填任何回饋欄位，系統會當成歷史資料整理，不通知。

### 檔案存在哪

`藝人專區 / 任務類型 / YYYY-MM / YYYY.MM.DD_任務名稱 / 任務名稱_YYYY.MM.DD_ver.N`

藝人專區只分享給該藝人本人。老師批改檔放在同一任務下的 `老師回饋/` 子夾。

## 流程六：日常監控

### `/任務總覽` — 看所有人的進度

一次列出所有未結案任務，分成：

> 🔴 已逾期 ／ 🛠 需修改 ／ ⏰ 三天內截止 ／ 📋 進行中・待提交 ／ 📮 待審核

**這是判斷藝人進度最快的方式。** 狀態是系統依實際動作自動變的，不是藝人自己回報：

- 還停在 `尚未開始` → 他連「收到任務」都還沒按
- `進行中` → 他確認收到了
- `待審核` → 他已經交了

任務多的時候會分頁。**唯讀，不寫任何東西。**

### `/任務通知重送` — 重新派發通知

**什麼時候用**

| 情境 | 說明 |
|---|---|
| 藝人一直沒反應 | 沒按「收到任務」，想再推一次 |
| **任務發出後才發現要改** | 時間填錯、地點變更、要求補齊——改完要重發 |
| 通知漏掉某些人 | 補了 Discord User ID 之後重送 |

**怎麼用**

```
/任務通知重送                      ← 列出全部可重送的任務
/任務通知重送 關鍵字:編曲           ← 任務多的時候直接縮小範圍
```

選任務 → 二次確認 → **立即重新派發**（不用等 30 分鐘輪詢）。

選單會標示每筆的狀態：

| 標示 | 意思 |
|---|---|
| `⏳ 未確認` | 藝人還沒按「收到任務」 |
| `✅ 已確認` | 藝人按過了，但你還是可以重送 |

未確認的排在前面。下拉最多 25 筆，超過會提示你用 `關鍵字` 縮小範圍。

---

#### 情境：任務已經發出、藝人也確認了，但你要改時間

這是最常見的狀況。**完整步驟：**

```
1. 先去 Notion 把那筆 Task 改好
   └─ 改「開始日」「截止日」或「任務說明」
      ⚠️ 通知訊息的時間是讀 Notion 欄位，
         只改任務說明的文字沒有用

2. 回 Discord 的「營運操作」頻道
   └─ /任務通知重送 關鍵字:（任務名稱片段）

3. 選那筆任務（會看到 ✅ 已確認）
   └─ 按「確認重送」

4. 藝人立刻收到新通知，要重新按一次「收到任務」
```

**系統會自動清空 `Discord 通知時間` 和 `Discord 收到時間`**，所以：

> ✅ **不需要手動去 Notion 清空那兩個欄位。**
> 早期版本的重送清單會跳過已確認的任務，必須手動清欄位才叫得出來——現在已經修正，直接用指令即可。

重送後藝人要重新確認一次，這是刻意的：內容既然變了，舊的確認就不算數。

---

#### 另一種做法：取消勾選再勾回來

也可行，但**不建議**：

- 取消 `Discord 顯示` 後，系統要等**下一輪背景輪詢（最多 30 分鐘）**才會清除舊的通知紀錄
- 如果你取消後馬上勾回去，系統會認為「已經通知過」，**不會重送**
- 中間還有一段時間藝人在 `/我的任務` 看不到這筆任務

用 `/任務通知重送` 是立即的，也不會讓任務短暫消失。

## 流程七：布告欄

Notion 的「佈告欄／留言板／使用回饋」會自動同步到 `公告區`，**每 5 分鐘一次**。

想立刻同步就打 **`/布告欄同步`**。

- 新增的 Notion 項目 → 發成 Discord 公告
- 改了狀態、類別、日期、人員、置頂 → 更新原訊息
- 沒變的不會重複發

公告下方有「回報／留言」按鈕。使用者送出後，系統在同一個資料庫建一筆：`類別`=🙋 使用回饋、`狀態`=未處理，內容含 Discord 使用者與原公告連結。

## 流程八：伺服器初始化（一次性）

**`/伺服器初始化`** — 只有伺服器管理員能用，建立或對齊六個頻道與 `控方`／`藝人` 身分組。

兩階段：先顯示預覽，**按「確認初始化」前不會動任何東西**。完成後回傳 `.env` 要填的 ID 清單。

已有同名頻道會沿用並更新分類、主題、權限，不會重建。

---

## 系統會自己做的事（不用你操作）

背景每 **30 分鐘**檢查一次，所以任何自動通知**最晚會在 30 分鐘內送出**。

| 項目 | 觸發條件 | 時間規則 |
|---|---|---|
| **任務派發** | 勾 `Discord 顯示`、有關聯藝人、未結案 | 下一輪輪詢（≤30 分）|
| **課後作業通知** | 再勾 `是否開放提交` | 下一輪輪詢（≤30 分），每筆只發一次 |
| **未確認重送** | 藝人沒按「收到任務」 | **每 12 小時**，直到按下為止 |
| **截止前提醒** | 依 `提醒規則` | 不勾＝**截止前 5 天**；只勾「逾期」＝事前不提醒 |
| **逾期升級** | 過了截止日 | 逾期後第一輪輪詢，只發一次（狀態寫回 Notion 防重複）|
| **審核催辦** | 提交後未審核 | **滿 24 小時**才開始，之後**每 12 小時** |
| **修改期限提醒** | 接近 `修改期限` | 期限前提醒藝人，逾期通知控方 |
| **月度時間池催填** | 收集期未填完 | **截止前 6 小時**一次、**逾期後**一次，**總共只催兩次** |
| **月度時間池收齊** | 全員填完 | 立即通知控方，並停止該次收集的檢查 |
| **排課 SLA** | 流程拖太久 | **48 小時**升級通知、**72 小時**提示候選可能失效 |
| **布告欄同步** | 自動 | **每 5 分鐘** |

> **月度時間收集只催兩次**，這是刻意設計避免騷擾藝人。收集期設得長（例如 3 天）的話，中間會有很長一段完全不提醒——需要的話請自行在群組補提醒。

所有重要動作都會寫 `Audit Log`（事件名稱、操作類型、來源系統、操作者、前值後值、目標頁面、結果）。

## 所有時間設定一覽

### 可以調整的（改 `.env` 後重啟 Bot）

| 設定 | 目前 | 影響 |
|---|---|---|
| `REMINDER_INTERVAL_MINUTES` | 30 分鐘 | 所有自動通知的檢查頻率。改小＝反應快，但 Notion 請求變多 |
| `TASK_ACK_REMINDER_HOURS` | 12 小時 | 藝人沒按「收到任務」的重送間隔 |
| `REMIND_BEFORE_DEADLINE_HOURS` | 6 小時 | 月度收集截止前多久催未填的人 |
| `REVIEW_REMINDER_AFTER_HOURS` | 24 小時 | 提交後多久才開始催審核 |
| `REVIEW_REMINDER_INTERVAL_HOURS` | 12 小時 | 催審核的間隔 |
| `FILE_UPLOAD_WAIT_MINUTES` | 180 分鐘 | 給 Drive 連結後的上傳有效期 |
| `BULLETIN_SYNC_INTERVAL_MINUTES` | 5 分鐘 | 布告欄同步頻率 |
| `DEFAULT_REMINDER_RULES` | 5 天前 | 任務沒勾提醒規則時的預設 |

### 每次操作時決定的

| 項目 | 預設 | 在哪決定 |
|---|---|---|
| 月度收集截止 | 1 天（24 小時）| 打 `/時間資訊蒐集` 時填 `截止天數` |
| 修改期限 | 無預設 | 審核退回時當場選 **1～7 天** |
| 任務截止前提醒 | 前 5 天 | 每筆任務的 `提醒規則` 欄位 |

### 操作畫面的逾時

按鈕與選單放著不動會失效，重打指令即可，**不會遺失已送出的資料**。

| 畫面 | 逾時 |
|---|---|
| 一般選單、任務清單、審核清單 | 10 分鐘 |

## 出問題怎麼查

| 狀況 | 檢查順序 |
|---|---|
| **藝人沒收到通知** | ① `Discord 顯示` 有勾？② 有 `關聯藝人`？③ 藝人 Notion 有填 `Discord User ID`？④ 都有的話打 `/任務通知重送` |
| **通知發出去了但內容不對** | 先在 Notion 改好欄位（時間要改 `開始日`／`截止日`，不是只改說明文字），再用 `/任務通知重送` |
| **通知訊息沒有時間** | Task 的 `開始日`／`截止日` 是空的。補上後重送 |
| **重送後藝人說又要再按一次確認** | 正常。重送會清空確認紀錄，內容變了本來就該重新確認 |
| **藝人說看不到 `/我的任務`** | 他在錯的頻道打，只能在 `任務查詢入口` |
| **可排課藝人 0 位** | Artists 有填 `Discord User ID`？`合約狀態` 是不是 `暫停`／`封存`？ |
| **比對不到共同空檔** | 月份選錯？有人沒填？時長太長？既有任務佔滿了？ |
| **勾了開放提交但沒通知** | 等一輪輪詢（最多 30 分鐘）；再確認 `Discord 顯示` 也有勾 |
| **審核寫入失敗** | 確認 Submissions 有這四個欄位：`審核回饋`、`審核者`、`審核來源`、`審核通知時間` |
| **管理指令看不到** | 帳號有 Discord 管理員權限嗎？Bot 在線嗎？ |
| **藝人填錯時間** | 請他自己用 `/管理可配合時間` 刪除重填 |

查不出來時，看 Notion 的 `Audit Log`，裡面有每個動作的成功／失敗紀錄與錯誤訊息。

## 幾條要記得的原則

- **`Availability Slots` 不是正式行程**，只是藝人回報的可配合時間。正式安排一律回到 `Tasks`。
- **TimeTree 不會自動同步**，正式任務確認後人工補登。不一致時以 Notion 為準。
- **不要硬刪 Notion 資料**，系統設計是封存不刪除。
- **改欄位名稱會讓系統失效**。新增資料、新增選項值都安全；**改名、刪欄位、改型別、刪除重建資料庫會出事**，動之前先問。
