## 開始之前

**指令一律在 `營運操作` 頻道打。** 在別的頻道會被擋下來並提示你換頻道。

看不到管理指令的話：確認你的 Discord 帳號有管理員權限、Bot 在線。

六個頻道各自的用途：

| 頻道 | 誰用 | 做什麼 |
|---|---|---|
| `營運操作` | 控方 | 打所有管理指令 |
| `營運內部通知` | 控方 | 接收系統通知，不用打指令 |
| `公告區` | 全體（唯讀）| 公開任務與收集公告 |
| `時間管理` | 藝人 | 回報可配合時間 |
| `任務查詢入口` | 藝人 | 查任務、交作業 |
| `課程助教` | 藝人 | 問小律查自己的任務 |

> 💡 每個指令的參數與分支細節見 [DISCORD_COMMANDS.md](../operations/DISCORD_COMMANDS.md)；工程端的設定見 [設定與技術細節](../operations/SETTINGS.md)。

## 每月收集可配合時間

### 你要做的

在 `營運操作` 打 **`/時間資訊蒐集`**：

| 參數 | 填什麼 |
|---|---|
| `月份` | `2026-10` |
| `截止天數` | 預設 1（24 小時內回填）|
| `說明` | 選填，例如「請優先填週末」|

### 系統會做的

1. 讀 `Artists`，找出所有可排課藝人（有 Discord User ID、合約狀態為 `已簽約` 或 `洽談中`）
2. 在 `公告區` 發公告並 mention 這些藝人
3. 私訊每一位藝人
4. 寫一筆 `Audit Log`

### 藝人填完後

系統把每一筆寫進 **`Availability Slots`**：

> `可用時段名稱`、`填寫藝人`、`填寫人名稱`、`身份`=藝人、`來源`=Discord、`可用開始時間`、`可用結束時間`、`提交時間`、`是否逾期提交`、`備註`（收集月份與藝人備註寫在這）

全員填完，系統會通知你可以開始排課。

### 建議節奏

- 每月固定日期發一次，例如每月 25 號前收集下個月。
- 需要臨時更新時，可以再發一次 `/時間資訊蒐集`，但不是必要。
- 個別藝人補填或修改，請藝人自己用 `/管理可配合時間`。
- 藝人私訊失敗時，手動提醒他到公告或使用 `/管理可配合時間`。

### 有人沒填

請他自己打 `/管理可配合時間` 補，**不用重發公告**。系統也會自動催他。

### 發錯了要取消

打 **`/取消時間蒐集`**，選那一筆，確認。

會停掉：催填提醒、逾期通知、排課 SLA 升級。
**不會動到**：藝人已經填好的時段（保留，之後排課照樣可用）。

已經發出的公告與私訊收不回來——記得自己去 `公告區` 刪掉那則公告，並在群組說一聲。

> 收集如果已經全員填完、或逾期通知發過了，系統會自己結束，**不需要手動取消**。

## 排課

### 只想看看有沒有空檔

**`/時間交集查詢`** — 唯讀，**完全不會寫入 Notion**。

選月份、需要的時長、勾要比對的藝人 → 看共同空檔。

看完想排的話按「直接建立任務」就接到下面的流程；不想排就按「關閉」。

候選時段多的時候會自動分頁。除了「上一頁／下一頁」，下面還有**跳頁選單**可以直接跳到你要的日期：

```discord
跳到指定頁（目前第 1/8 頁）…
  第 1/8 頁   9/1 – 9/4    ← 目前
  第 2/8 頁   9/5 – 9/8
  第 3/8 頁   9/9 – 9/12
  ...
```

選單顯示的是**每頁涵蓋的日期範圍**，不是只有頁碼。想看 9 月下旬就直接挑那一頁，不用一頁一頁翻。

### 要直接排

**`/從時間池建立任務`** — 參數一樣（月份、時長分鐘）。

跟上面的差別：這支會**先自動整理藝人的時間池**（合併重疊、封存重複），所以比對用的是最乾淨的資料。整理動作會更新 `Availability Slots` 並寫 `Audit Log`。

### 選完候選時段之後

系統讓你選任務類型（選項直接從 Notion 的 `任務類型` 讀出來，Notion 加新選項這裡就會有）。

**選「課程時間&作業繳交」** → 再依序選課程類別、課程培訓 Project、負責老師，最後填課程名稱。

**選其他類型** → 再選精準時間，填地點等資訊。

每一層都可以「返回上一步」，Modal 取消也不會寫入任何東西。**只有走到最後才會真的建立。**

### 系統建立的東西

在 **`Tasks`** 建一筆：

| 欄位 | 寫入值 |
|---|---|
| `任務名稱` | 你填的 |
| `任務狀態` | `尚未開始` |
| `任務類型` | 你選的 |
| `關聯藝人` | 你勾的藝人 |
| 任務內頁（`## 任務說明` 標題底下） | 候選時段等資訊 |
| `是否開放提交` | `false` |
| **`Discord 顯示`** | **`false`** |
| `課程類別`／`負責老師`／`關聯專案` | 課程流程才有 |
| `開始日`／`截止日` | 有選精準時間才有 |

> **重點：建立當下 `Discord 顯示=false`，所以藝人不會收到任何通知。** 這是草稿，等你補完內容再開。

> ⚠️ **課程任務一定要在內頁補一段給藝人看的內容**：系統寫的候選時段等資訊藝人看不到。寫法見「任務內頁怎麼寫」。

回覆訊息會附上那筆 Notion Task 的連結，直接點進去編輯。

> ⚠️ **草稿不再佔掉藝人的時段**（2026-09-18 起）。以前藝人填可配合時間時，系統會把未勾 `Discord 顯示` 的草稿也算成「已排定」自動排除掉，**連草稿的任務名稱都會顯示給藝人**，這個問題已經修掉了。
>
> **代價**：藝人填時段時看不到這筆草稿，可能把那個時段回報成「可以配合」。**所以時間一旦談定就要盡快勾 `Discord 顯示`**，不要長期擺著當草稿。
>
> 你這邊不受影響：`/時間交集查詢` 比對共同空檔時**仍然**會把草稿算成已佔用，不會把已經排掉的時間當空檔推給你。

### 怎麼看候選時段

- 候選時段已依這次需求時長切好；例如需要 1 小時，就會顯示一小時一列。
- 候選起點每 30 分鐘切分，例如 `13:30-14:30`、`14:00-15:00`。
- 比對會扣除 Tasks 中已填寫正式時間的硬性任務（錄音、演出、會議溝通，以及有課程類別的課程）。作業、創作交付、企劃、行政、發布上架只提醒，不封鎖整天。
- 有人沒填：先請他用 `/管理可配合時間` 補。
- 沒有共同空檔：縮短時長、改選藝人，或請藝人補更多時段。

### 時間拖太久

藝人預設 24 小時內回填；截止後半天仍未比對會提醒你；整個流程超過 48 小時升級通知，72 小時提示候選可能已經失效。

### TimeTree 補登

TimeTree 沒有自動同步。正式任務確認、Discord 通知發出後，由你人工補登 TimeTree。TimeTree 只是過渡期的行事曆，**兩邊不一致時以 Notion 為準**，再回頭修正 TimeTree。

## 建立任務與欄位

不論是系統建的草稿，還是你自己在 Notion 開的任務，欄位規則都一樣。

### 例會後怎麼建

例會確認的正式事項，**不要寫成 Availability Slot**，一律建 `Project`／`Task`：

1. 有上層企劃、活動、作品、月度任務時，先建 `Project`。
2. 具體要做的事情建 `Task`，掛上 `關聯專案`（沒掛的話，交件檔案會進「未分專案」資料夾）。
3. 依下面的表填欄位。
4. 內頁寫給藝人看的任務內容（見「任務內頁怎麼寫」）。
5. 確認無誤才勾 `Discord 顯示`，藝人才會收到通知。

### 一定要填

| 欄位 | 為什麼 |
|---|---|
| `任務名稱` | 藝人看到的標題 |
| `任務類型` | 決定要不要佔用藝人時段、要不要發公告區。課程固定選 `課程時間&作業繳交`，再填 `課程類別` |
| `關聯藝人` | **沒填就沒有藝人會收到通知**（公司同仁另填 `相關同仁`，見下方） |
| `開始日`／`截止日` | 正式行程時間，也是提醒與逾期判斷的依據。**不要把 `截止日` 改成作業期限**，作業期限填 `提交期限` |

### 任務相關對象：關聯藝人與相關同仁

任務相關對象由兩欄組成，分屬 Artists、People 兩個資料庫，請依角色分開填寫：

1. 先判斷對方是否要**執行、確認或交件**：是，就填 `關聯藝人`；不是，不要放在這欄。
2. 若對方只是需要**知道任務與期限**（老師、公司同仁），填 `相關同仁`。
3. 同一筆任務可以兩欄都填：藝人會收到可操作的任務訊息；同仁會收到純知會。
4. 派發前確認每位對象在各自資料庫都有 `Discord User ID`。

| 對象角色 | 填哪一欄 | Discord 收到什麼 | 能否改任務狀態 |
|---|---|---|---|
| 藝人執行者 | `關聯藝人` | 任務卡（收到任務／有問題按鈕）、每日早報、交件與審核結果 | 可以 |
| 老師／公司同仁 | `相關同仁` | 派發知會、每日同仁早報，沒有按鈕 | 不可以 |

> ⚠️ **People 沒填 `Discord User ID` 的同仁一定收不到**，系統也不會另外提醒你。新增同仁時記得補。

> ⚠️ 不要建立或使用 `相關人士` 欄位：Notion 的一個 Relation 不能同時連到 Artists 與 People，本系統用這兩欄共同表示「任務相關對象」。

### 控制系統行為的三個開關

| 欄位 | 勾了會怎樣 |
|---|---|
| **`Discord 顯示`** | 藝人收到私訊通知，並出現在他的 `/我的任務`。**沒勾＝完全不通知** |
| **`是否開放提交`** | 藝人可以交件。**任何任務類型都適用**，不是只有課程。⚠️ 沒勾的任務過了截止，系統不會判逾期，改列「等你確認結案」（見「不用交件的任務過了截止」） |
| **`提前交件`** | 第一輪交件日自動提前到截止日前 5 天（見「三個日期欄位」）。**上課、通告不要勾** |

### 要交件才填

| 欄位 | 說明 |
|---|---|
| `提交期限` | 第一輪什麼時候交。**不要改 `截止日`**，那是正式行程時間。勾了 `提前交件` 可留空讓系統算 |
| `審核人員` | 指定誰審，選 People 中 `身份類型=公司成員` 的人；不填就由控方審。每天 10:00 會私訊審核人員待審的提交 |

> 💡 **交件一律上傳到公司 Drive**（2026-10-11 起）。`提交方式` 欄位已刪除；藝人要交文字內容就存成檔案上傳。

### 選填

| 欄位 | 說明 |
|---|---|
| `提醒規則` | **不勾也會在死線前 5 天、3 天各提醒一次**（系統預設）。勾的是**額外再加**的（3 天前／1 天前／當天，可複選），沒有辦法減少。算的是**死線**前幾天，不是截止日前幾天 |
| `負責老師`／`課程類別` | 課程任務用。課程結束後系統會提醒負責老師到論壇發布（見「系統會自己做的事」） |
| `相關同仁` | 要讓老師／公司同仁收到這筆任務的知會就填。這不是 `負責老師` 的替代欄位 |
| `關聯專案` | 有上層企劃時填；決定交件檔案放在哪個 Drive 資料夾 |

> 💡 預設提醒「5 天前＋3 天前」和勾選是**疊加**的：預設永遠生效，勾選只能往上加，所以只勾「逾期」不能關閉事前提醒。Notion 的 `提醒規則` 選項裡沒有「5 天前」是刻意的：預設已經包含，加回選項勾不勾都一樣。

### 公開類型

`任務類型` 是 **`通告`** 或 **`演出`** 時，除了私訊藝人，還會發到公告區、列進「本月排程」，全體看得到。其他類型只私訊關聯藝人。

## 三個日期欄位：截止日、提交期限、修改期限

這三欄看起來很像，**其實是任務一生中三個不同的時刻**。搞混的話提醒會發在錯的日子。

```text
控方建任務 ──▶ 派發 ──▶ 藝人第一次交 ──▶ 審核 ─┬─ 通過 ✓
                           ▲                     │
                      [提交期限]                  └─ 需修改／退回
                                                        │
                                                        ▼
                                              藝人重交 ──▶ 審核 ──▶ …
                                                 ▲
                                            [修改期限]

                         ────────── [截止日] ──────────▶
                         （對外發布／上課那一天，跟「交」無關）
```

| 欄位 | 是什麼 | 誰填 | 什麼時候存在 |
|---|---|---|---|
| **`截止日`** | **事情發生的那天**：發布日、上課日、演出日 | 你 | 一開始就有 |
| **`提交期限`** | **第一輪**交件的死線 | 你，或勾 `提前交件` 讓系統算 | 派發時 |
| **`修改期限`** | **第二輪起**重交的死線（審核退件後才有） | 系統，`/審核提交` 選 1～7 天時寫入 | 只有退件後 |

`提交期限` 和 `修改期限` 都是「交」，但一個是還沒審過的第一版、一個是審過被退的修改版。**任務不會同時在兩個階段**，所以系統永遠只看其中一個。

### 系統當下追哪一天（死線判定）

看 `任務狀態` 先分兩輪：

```text
任務狀態 = 需修改？
   ├─ 是 → 死線 = 修改期限（第二輪，其他日期全部不看）
   └─ 否 → 第一輪：
         提前交件 ☑？
            ├─ 是 → 提交期限有填？→ 用它
            │             沒填？→ 截止日 − 5 天
            └─ 否 → 是否開放提交 ☑ 且 提交期限有填？→ 用提交期限
                                       否則         → 截止日
```

### 全部情境（截止日 9/30、提交期限若有填＝9/27、修改期限 10/3）

### 提前交件的任務：9/25 沒交就是逾期

## 任務內頁怎麼寫

總表的 `任務說明` 欄位**已廢除**。藝人、同仁看到的任務內容，一律是**點進任務後的內頁整頁**。

**怎麼寫**

1. 點進任務，直接在內頁寫。**不用加標題**；有 `## 任務說明` 標題也可以（時間池建的任務會自動加），只是當記號。
2. 寫清楚**做什麼、做多少、用什麼形式交、什麼時候交**，例如「聽力訓練：50 題音程／截圖」。藝人沒有別的地方可以查，小律回答細節也只看這一頁。
3. 時間要改 `開始日`／`截止日` 欄位；內頁裡寫的時間不會被系統當成正式時間。

**會被讀到的**：一般段落、標題、條列、待辦、引用、callout、切換清單裡面、分欄裡面、表格（每列變成「欄｜欄」）、書籤／嵌入的網址。巢狀最多讀 3 層。

**不會被讀到的**
- **子頁面、連結的資料庫**：要放不想給藝人看的東西，就放子頁面。
- **圖片、檔案、PDF**：藝人收不到附件。要給檔案，請放 Drive 連結（網址會保留）。
- 系統自己寫的兩段：**「藝人回覆」**（藝人按「有問題」時寫入）、**「Drive 資料夾索引」**（多人任務首次交件時寫入）。

**⚠️ 要注意的事**

| 注意 | 為什麼 |
|---|---|
| **整頁都會被藝人看到** | 派發通知、截止前提醒、藝人／同仁早報、小律念的都是這一頁。內部備註、報價、參考文章、其他藝人的資訊**不要放在內頁**，放子頁面 |
| **Notion 網址會被拿掉** | 藝人端零 Notion 入口（M7-04），內頁貼的 Notion 連結藝人看不到；Drive、YouTube 等其他網址保留 |
| **`名稱：` 開頭的行會被濾掉** | `安排來源：`、`課程類別：`、`負責老師：`、`需要時長：`、`候選時段`… 這類行首字樣是時間池寫的控方欄位，藝人看不到。要交代就寫成一句話（「這週改由 B 老師上課」） |
| **太長會被截斷** | 派發通知最多約 900 字、截止前提醒 700 字、交件清單 120 字摘要、小律與「看詳細」1,500 字。重點寫在最前面 |
| **已發出的通知不會自己更新** | 改了內頁，已經送出的私訊還是舊內容；要藝人看到新版，用 `/任務通知重送` 或勾 `重送通知`。早報、小律下次讀就是新的 |
| **不要改系統段落的標題** | 「藝人回覆」「Drive 資料夾索引」改名的話，系統會把它當成任務內容念給藝人 |
| **讀不到內頁時顯示「尚未填寫」** | Notion 暫時出錯時，那一輪通知會寫「Notion 尚未填寫任務說明」。內頁確定有寫卻出現這句，等下一輪或重送 |
| **內頁空白** | 藝人只會收到「Notion 尚未填寫任務說明」，派發前先確認 |

**欄位廢除的順序（一次性，2026-10-21）**：① 舊欄位內容搬進內頁（已完成：94 筆）→ ② 重開 bot → ③ 控方從 Notion 刪 `任務說明` 欄位。**順序不能反**：先刪欄位、舊程式還在跑的話，舊欄位那批任務的說明會變空白。

### ⚠️ 課程任務一定要自己補一段

`/時間交集查詢` 建出來的課程任務，任務內頁會長這樣（Bot 會自動加 `## 任務說明` 標題）：

```notion
安排來源：/從時間池建立任務
課程類別：舞蹈課
負責老師：lurasupa
需要時長：2 小時
候選時段（由營運最後確認）：
2026-09-17 19:30~21:30
```

**這些全部是給你看的，藝人一行都看不到。** 系統會自動濾掉 `安排來源：`、`課程類別：`、`負責老師：`、`需要時長：`、`候選時段` 這類控方內部欄位，所以濾完是空的，藝人收到的就是「Notion 尚未填寫任務說明」。

**做法**：在這段文字下面**另起一行**寫給藝人的內容，例如：

```notion
（上面 Bot 產生的內容不用動）

這週練上次那支編舞的後半段，記得帶練習服。
```

你加的這行不會被濾掉，會原樣出現在藝人的通知裡。兩者可以共存，不必刪掉 Bot 產生的部分。

> **寫的時候避開 `名稱：` 這種格式開頭**。過濾是比對行首關鍵字，你若寫成「負責老師：換成 B 老師」也會被當成內部欄位濾掉。要交代這類事情就寫成一句話，例如「這週改由 B 老師上課」。

### 勾下 `Discord 顯示` 之後

## 收件與審核

### 藝人交件時系統做的事

在 **`Submissions & File Index`** 建一筆：

> `提交名稱`、`提交藝人`、`關聯任務`、`提交來源`=Discord、`提交類型`、`檔案類型`（依任務類型自動對應）、`審核狀態`=待審核、`權限等級`=藝人本人、`是否最新版`=true、`提交時間`
> 另外寫 `Drive URL`、`Drive File ID`、`原始檔名`、`檔案大小 MB`（交件一律是檔案）

同時：
- 同一任務的舊提交自動取消 `是否最新版`（永遠只有一筆最新）
- Task 的 `任務狀態` 變 `待審核`、`最新提交 URL` 回寫
- 你在 `營運內部通知` 收到提醒

### 你要做的

在 `營運操作` 打 **`/審核提交`**：

1. 選一筆待審核的
2. 系統列出 Drive 連結、關聯任務，**先看過再判斷**
3. 選 `通過`／`需修改`／`退回`
4. 填給藝人的回饋（可留空）
5. 選需修改或退回時，要填 **1～7 天的修改期限**
6. 送出後，系統**馬上**私訊藝人審核結果與你填的回饋（第一則）
7. 接著問你要不要補批改檔：
   - 沒有 → 按「**不需補批改檔**」，流程結束
   - 有 → 按「**附批改檔**」，見下方

### 附批改檔

1. 按「附批改檔」後，直接在**同一個頻道**上傳批改檔，可以連續傳多個
2. 全部傳完按「**完成回饋**」（還沒傳任何檔案就按，系統會請你先上傳）
3. 系統把檔案歸檔到該藝人的 Drive（`老師回饋/` 子夾），連結寫進 Submissions 的 `審核回饋`，並私訊藝人批改檔連結（第二則）

注意：
- **每個檔案要在 10MB 以下**（這是目前唯一還收 Discord 附件的地方）。更大的檔案請先上傳到系統提供的老師回饋 Drive 資料夾，再按「**貼 Drive 連結補回饋**」，把連結貼進表單（必填）
- 這則訊息只有你看得到，**切去 Drive 上傳再回來時可能已經消失**。沒關係：3 小時內回到同一個頻道隨便打一句話（例如「好了」），系統會再給你「貼 Drive 連結補回饋／完成回饋」按鈕
- 入口 **3 小時**內有效。審過的提交不會再出現在 `/審核提交`，所以逾時就沒有 Discord 入口了：請把 Drive 連結直接貼到 Notion 那筆 Submissions 的 `審核回饋`，並自己私訊藝人（系統不會再通知）
- 這個回饋入口只有原本審核的那個人能操作
- 按錯想重選，用「返回回饋選擇」

**藝人會收到兩則私訊**：第一則是審核結果（通過／需修改／退回＋回饋），審核一送出就發；第二則是「📎 老師補充了批改檔」，在你按「完成回饋」（或貼連結送出）之後才發。選「不需補批改檔」的話，藝人只會收到第一則。兩則都不含 Notion 連結。

### 系統寫回

| 動作 | 寫入 |
|---|---|
| 審核完成 | Submissions 的 `審核狀態`、`審核回饋`、`審核者`、`審核來源` |
| 通知藝人後 | `審核通知時間` |
| 通過 | Task `任務狀態` → `已完成` |
| 需修改／退回 | Task `任務狀態` → `需修改`、寫入 `修改期限` |

### 也可以在 Notion 直接審

改 `審核狀態`，然後**至少填 `審核回饋`、`審核者`、`審核來源` 其中一個**。系統背景偵測到才會通知藝人。只改狀態不填任何回饋欄位，系統會當成歷史資料整理，不通知。

### 檔案存在哪

`藝人專區 / 專案名稱 / YYYY.MM.DD_任務名稱 / 任務名稱_YYYY.MM.DD_ver.N`，跟 Notion 的專案一致；沒掛專案的任務放 `未分專案`（2026-10-18 上線，取代舊的「任務類型／月份」結構）。你要注意兩件事：
- 任務一定要掛 `關聯專案`，否則檔案會進「未分專案」
- **專案建好後盡量不要改名**，改了之後新交的檔案會在新名稱的資料夾，跟舊的分開

細節見規則頁 M4-07。

藝人專區只分享給該藝人本人。老師批改檔放在同一任務下的 `老師回饋/` 子夾。

藝人重新進入同一筆任務的交件（例如去 Drive 上傳回來、訊息消失了），3 小時內會回到同一個 `ver.N` 資料夾，不會再開新的；交出去之後再交才會開下一個 ver。

## 日常監控與重送

### `/任務總覽` — 看所有人的進度

一次列出所有未結案任務，分成：

> 🔴 已逾期 ／ 🛠 需修改 ／ ⏳ 已過截止，等公司確認 ／ ⏰ 三天內截止 ／ 📋 進行中・待提交 ／ 📮 待審核

**這是判斷藝人進度最快的方式。** 狀態是系統依實際動作自動變的，不是藝人自己回報：

- 還停在 `尚未開始` → 他連「收到任務」都還沒按
- `進行中` → 他確認收到了
- `待審核` → 他已經交了

任務多的時候會分頁。除了「上一頁／下一頁」，也有**跳頁選單**，標示每頁有哪些分區：

```discord
跳到指定頁（目前第 1/3 頁）…
  第 1/3 頁   🔴 已逾期、🛠 需修改   ← 目前
  第 2/3 頁   📋 進行中／待提交
  第 3/3 頁   📮 待審核
```

**想直接看逾期的就挑那一頁**，不用從頭翻。

**唯讀，不寫任何東西。**

### `/任務通知重送` — 重新派發通知

**什麼時候用**

| 情境 | 說明 |
|---|---|
| 藝人一直沒反應 | 沒按「收到任務」，想再推一次 |
| **任務發出後才發現要改** | 時間填錯、地點變更、要求補齊——改完要重發 |
| 通知漏掉某些人 | 補了 Discord User ID 之後重送 |

**怎麼用**

```text
/任務通知重送                      ← 列出全部可重送的任務
/任務通知重送 關鍵字:編曲           ← 任務多的時候直接縮小範圍
```

選任務 → 二次確認 → **立即重新派發**（不用等 30 分鐘輪詢）。

**一次要重送很多筆**：在 Notion 的 Tasks 勾 `重送通知`（可以多選後批次勾），下一輪（最多 30 分鐘）系統會逐筆重送、自動取消勾選，並在 `營運內部通知` 發一則結果摘要。沒勾 `Discord 顯示` 或已結束的任務會略過。

選單會標示每筆的狀態：

| 標示 | 意思 |
|---|---|
| `⏳ 未確認` | 藝人還沒按「收到任務」 |
| `✅ 已確認` | 藝人按過了，但你還是可以重送 |

未確認的排在前面。下拉最多 25 筆，超過會提示你用 `關鍵字` 縮小範圍。

---

#### 情境：任務已經發出、藝人也確認了，但你要改時間

這是最常見的狀況。**完整步驟：**

```text
1. 先去 Notion 把那筆 Task 改好
   └─ 改「開始日」「截止日」或任務內頁
      ⚠️ 通知訊息的時間是讀 Notion 欄位，
         只改內頁裡寫的時間沒有用

2. 回 Discord 的「營運操作」頻道
   └─ /任務通知重送 關鍵字:（任務名稱片段）

3. 選那筆任務（會看到 ✅ 已確認）
   └─ 按「確認重送」

4. 藝人立刻收到新通知，要重新按一次「收到任務」
```

**系統會自動清空 `Discord 通知時間` 和 `Discord 收到時間`**，所以：

> ✅ **不需要手動去 Notion 清空那兩個欄位。**
> 早期版本的重送清單會跳過已確認的任務，必須手動清欄位才叫得出來——現在已經修正，直接用指令即可。

重送後藝人要重新確認一次，這是刻意的：內容既然變了，舊的確認就不算數。

---

#### 另一種做法：取消勾選再勾回來

也可行，但**不建議**：

- 取消 `Discord 顯示` 後，系統要等**下一輪背景輪詢（最多 30 分鐘）**才會清除舊的通知紀錄
- 如果你取消後馬上勾回去，系統會認為「已經通知過」，**不會重送**
- 中間還有一段時間藝人在 `/我的任務` 看不到這筆任務

用 `/任務通知重送` 是立即的，也不會讓任務短暫消失。

## 營運內部通知

**`營運內部通知` 頻道會看到三種（2026-10-20 起，M3-25）**：

| 開頭 | 是什麼 | 你要做的 |
|---|---|---|
| 📋 營運早報 | **每天 09:30 一則**：已過截止等你確認結案（不用交件的任務，M2-14）、新逾期、仍逾期（各藝人筆數）、修改期限已過、待審核超過 24 小時沒人負責、藝人還沒按收到超過 3 天、昨天的早報沒看的藝人、老師課後作業（聯絡不到或催滿 7 天）、時間池進度、週一的發文待確認。前一天的會自動刪掉 | 看完逐項處理；每一筆任務名稱都是 Notion 連結，可以直接點開；下方選單可以在同一則看某一筆的詳細 |
| 🟥 要處理 | 新提交但沒指定審核人、藝人回報任務問題、任務通知送不出去。即時發 | 接手時按「🙋 我來處理」（別人會看到你處理中），處理完按「✅ 已處理」收成一行。**按鈕不改 Notion**，真正的處理要到 Notion 做，見「Discord 按鈕與 Notion 欄位的連動」 |
| ⚙️ 系統警告 | Drive 授權失效、Notion 選項對不上。很少出現 | 照訊息裡的修法處理；Drive 恢復時同一則會變成 🟢 |

**每一則跟某一筆任務有關的通知，都會附那筆任務的 Notion 連結**（早報裡是任務名稱本身可以點；🟥 要處理在訊息最後一行 🔗）。連結只出現在這個頻道，藝人和同仁收到的訊息一律不帶 Notion 連結。早報太長放不下連結時，會自動改成純文字，要看某一筆就用下方選單。時間池進度、系統警告不是單一任務，沒有連結。

另外仍會即時通知：時間池**收齊**、排課 SLA、批次重送結果。控方通知**只會發到 `營運內部通知`**，這個頻道沒設定時只寫記錄檔，不會改發到藝人看得到的頻道。想回到一則一則的舊式通知，請找工程端關掉營運早報。

## Discord 按鈕與 Notion 欄位的連動

Discord 上的按鈕分兩種：**藝人按的會改 Notion**，**控方按的不會**。營運早報不靠按鈕，每天直接讀 Notion 當下的狀態。搞混的話，常見的誤會是「我在 Notion 處理完了，為什麼頻道那則還是 🟥」，或「我按了已處理，為什麼 Notion 沒變」。

### 一、控方的按鈕（`營運內部通知`）：只是 Discord 上的標記，不改 Notion

| 按鈕／選單 | 出現在哪 | 改 Tasks 欄位嗎 | 實際會發生什麼 |
|---|---|---|---|
| 🙋 **我來處理** | 🟥 要處理的訊息 | **不改** | 那則訊息多一行「👤 名字 處理中（月/日 時:分）」；Notion 的 Audit Log 記一筆（誰、幾點、哪則） |
| ✅ **已處理** | 🟥 要處理的訊息 | **不改** | 整則收成一行「✅ 已處理｜標題｜名字 時間」，按鈕消失；Audit Log 記一筆 |
| **看某一筆的詳細** | 📋 營運早報 | **不改**，只讀 | 在同一則訊息下方展開那筆任務的內容、藝人、Notion 連結；再選別筆就換成那一筆 |

**雙向都不連動**：

- 你按「已處理」，Notion 上的任務**不會**改狀態、不會結案、不會重新派發。真正的處理一定要到 Notion 做。
- 你在 Notion 把事情處理完，那則 🟥 **不會**自己收起來，要回頻道按「已處理」。
- 不按也不影響任何功能，只是頻道裡看不出這件處理過沒。

**三種 🟥 要處理，到 Notion 要做的事**：

| 🟥 通知 | 為什麼會出現 | 到 Notion 怎麼處理 | 處理完 |
|---|---|---|---|
| **藝人回報任務問題** | 藝人按了「有問題，無法配合」。系統已經把任務退回 `尚未開始`、取消 `Discord 顯示`，原因寫在任務內頁的「藝人回覆」段落 | 看「藝人回覆」，改任務內容／時間，重新勾 `Discord 顯示`（下一輪最多 30 分鐘重新派發給藝人） | 回頻道按「✅ 已處理」 |
| **新提交（沒有指定審核人）** | 藝人交件了，但任務的 `審核人員` 沒填，或填的人沒有 Discord ID，沒有人收到審核通知 | 用 `/審核提交` 審這筆；之後同類任務記得填 `審核人員` | 按「✅ 已處理」 |
| **任務通知送不出去** | 任務勾了 `Discord 顯示`，但關聯藝人／相關同仁都沒有 `Discord User ID`，派發卡發不出去 | 到 Artists／People 補 `Discord User ID`，再勾 `重送通知`（或用 `/任務通知重送`） | 按「✅ 已處理」 |

這三種 Notion 上都沒有一個欄位能代表「這則警告處理完了」，所以系統沒辦法自己判斷，只能靠人按。

### 二、藝人的按鈕（私訊）：會直接改 Notion

| 按鈕 | 出現在哪 | 會改的 Tasks 欄位 | Discord 上的變化 |
|---|---|---|---|
| **收到任務** | 派發卡 | `任務狀態` → `進行中`；`Discord 收到時間` → 按的時間 | 那則收成一行「✅ 已收到｜任務｜時間」，同任務其他舊通知刪掉 |
| **有問題，無法配合** | 派發卡 | `任務狀態` → `尚未開始`；`Discord 顯示` → 取消勾選；`Discord 通知時間`、`Discord 收到時間` → 清空；`提醒確認(From 藝人)` → 清空；藝人填的原因追加到任務內頁「藝人回覆」段落 | 營運內部通知收到一則 🟥 藝人回報任務問題 |
| 👌 **我都看到了** | 每日早報 | `提醒確認(From 藝人)` 每筆任務加一行「早報｜時間｜藝人」 | 早報收成一行「✅ 已讀（時間）」 |
| **看某一筆的詳細** | 每日早報 | **不改**，只讀 | 在同一則下方展開任務內容 |
| **交件** | `/我的任務` → 提交任務 | 建一筆 Submission（舊的那筆 `是否最新版` 取消）；`任務狀態` → `待審核`；`最新提交 URL` 回寫；`修改期限` 清空 | 審核人員（沒有就是營運內部通知）收到新提交通知 |

⚠️ `提醒確認(From 藝人)` 欄位**還沒在 Notion 建立**（Tasks 卡「建立 提醒確認(From 藝人) 欄位」）。沒建之前，「我都看到了」只記在 Audit Log，Notion 任務上看不到；建好之後不用改程式就會開始寫。

### 三、營運早報：每天 09:30 直接讀 Notion，跟著你的修改自動更新

營運早報沒有要按的按鈕，它每天重新讀一次 Notion。你今天在 Notion 改了什麼，**隔天的早報就會反映**：

| 早報那一區 | 你在 Notion 做的事 | 隔天早報 |
|---|---|---|
| ⏳ 已過截止，等你確認結案 | 改成 `已完成`／`已完成發文` | 不再列 |
| | 延後 `截止日` | 不再列，藝人回到正常提醒 |
| | 改成 `已逾期` | 移到「仍逾期」 |
| 🔴 新逾期／仍逾期 | 結案，或延期限並改回 `進行中` | 不再列 |
| 🛠 修改期限已過 | 藝人重交（變 `待審核`），或延後 `修改期限` | 不再列 |
| 📮 待審核超過 24 小時，沒人負責 | 審完；或填好有 Discord ID 的 `審核人員` | 不再列（之後改由審核人員每天 10:00 收提醒） |
| 📌 藝人還沒按收到超過 3 天 | 藝人按了收到 | 不再列 |
| 📣 發文待確認發布（週一） | 改成 `已完成發文` | 不再列 |

前一天的營運早報會自動刪掉，頻道裡永遠只有今天那則。

### 四、常見誤會

| 你遇到的狀況 | 原因 | 怎麼做 |
|---|---|---|
| Notion 處理完了，頻道那則還是 🟥 | 🟥 不讀 Notion | 回頻道按「✅ 已處理」 |
| 按了「已處理」，Notion 任務沒變 | 按鈕只是標記 | 到 Notion 實際處理 |
| 同事按了「我來處理」，我還要處理嗎 | 不用，那行就是告訴你有人接了 | 等他按「已處理」 |
| 按鈕按了沒反應 | bot 沒在線，或 Discord 一時沒回應 | 等一下再按；bot 重開後舊訊息的按鈕仍然按得到 |
| 營運早報上的事我處理完了，今天的早報還在列 | 早報一天只發一次，是 09:30 當下的狀態 | 不用管，明天就不會列 |
| 想知道誰處理了某則 🟥 | 收合後那一行有名字和時間 | 訊息被刪了的話，查 Notion 的 Audit Log |

## 不用交件的任務過了截止

沒勾 `是否開放提交` 的任務（發文、出席、提大綱、行政），藝人做完了系統不會知道，有沒有完成是你判斷的。為了不讓「其實做完了、只是你還沒結案」的任務被當成逾期，**這類任務過了截止，系統不會自動改成 `已逾期`**。

**每天你要做的**：看營運早報的「⏳ 已過截止，等你確認結案」，點任務連結確認：

| 確認結果 | 在 Notion 怎麼改 | 藝人看到 |
|---|---|---|
| 做完了 | `已完成`（發文類改 `已完成發文`） | 隔天早報不再列 |
| 沒做，希望他補 | 延後 `截止日` | 早報回到「⏰ 快到期」 |
| 沒做，要講重一點 | 手動改成 `已逾期` | 早報出現「🔴 已逾期」 |
| 還不確定 | 不用動 | 早報每天列「⏳ 已過截止，等公司確認」 |

**會怎麼呈現**（例：SOMA「10/20（二）發布：吃宵夜 POV」，不用交件、截止 10/20、控方還沒結案）

- **Notion**：`任務狀態` 維持原本的 `進行中`（藝人沒按收到的話是 `尚未開始`），系統不會改它。看起來跟還沒到期的任務一樣，要看截止日才分得出來，所以每天以營運早報那一區為準。
- **營運早報**（09:30，`營運內部通知`）：

  ```discord
  ⏳ 已過截止，等你確認結案（1）
  做完了就結案；沒做可以延期限或改成「已逾期」。
  ・SOMA｜發布：吃宵夜 POV｜截止 10/20（已過 1 天）
  ```
  任務名稱是 Notion 連結，點了直接開那筆任務；下方選單也看得到這筆。

- **藝人早報**（09:00 私訊；有掛相關同仁的話，同仁早報也一樣）：

  ```discord
  ⏳ 已過截止，等公司確認（1）
  ・10/20（二）發布：吃宵夜 POV｜截止 10/20（已過 1 天）
  還沒做完請盡快完成；已經做完不用理會，公司會確認。
  ```

- **藝人的 `/我的任務`**：多一個分區「⏳ 已過截止，等公司確認」，排在「🛠 需修改」之後。
- **你改成 `已逾期` 之後**：藝人早報改列「🔴 已逾期」，營運早報改列在「仍逾期」的筆數裡。

**要注意**
- **你不處理，它就每天列著**：藝人早報、營運早報都會一直列，直到你結案、延期或改成已逾期。
- **要交件的任務不受影響**：有勾 `是否開放提交` 的，過了死線照舊自動改 `已逾期`；藝人交件後變 `待審核`。
- **任務要交件但還沒勾開放提交**：系統一樣當成「不用交件」處理。所以要交件的任務，截止前記得勾 `是否開放提交`。
- **課程培訓**照舊不判逾期（M5-03）。
- **`已逾期` 的意思變了**：不用交件的任務，`已逾期` 只會是你手動改的，代表你確認過真的沒做。2026-10-21 之前系統自動改成 `已逾期` 的 9 筆維持原樣，照常確認後結案即可。

## 系統會自己做的事

背景每 **30 分鐘**檢查一次，所以任何自動通知**最晚會在 30 分鐘內送出**。

| 項目 | 觸發條件 | 時間規則 |
|---|---|---|
| **任務派發** | 勾 `Discord 顯示`、有關聯藝人或相關同仁、未結案 | 下一輪輪詢（≤30 分）|
| **課後作業通知** | 再勾 `是否開放提交` | 下一輪輪詢（≤30 分），每筆只發一次 |
| **每日早報**（M3-24） | 每位藝人有已逾期、需修改、已過截止等確認、快到期、還沒按收到的任務 | **每天 09:00 一則**，取代逐則私訊。藝人用選單看細節、按「👌 我都看到了」；每筆任務的 `提醒確認` 會記「早報｜時間｜已發送給 N 人」和「早報｜時間｜藝人」。隔天發新的時刪掉前一天的。已逾期、需修改確認過後隔天仍列，標「⚠️ 仍未完成」。要回到逐則通知請找工程端 |
| **沒按收到** | 藝人沒按「收到任務」 | **不再重送**，改列在藝人早報的「📌 還沒按收到」；超過 3 天也列在營運早報 |
| **截止前提醒** | 預設＋`提醒規則` | 一律**死線前 5 天、3 天**，勾的再加。到期的階段**排進當天早上的早報**，不再一則一則私訊藝人；相關同仁改收每天一則同仁早報（跟藝人早報同時發）。提前交件任務的死線＝交件日（截止日 − 5） |
| **逾期升級** | **要交件的任務**（有勾 `是否開放提交`）過了死線 | 狀態改 `已逾期`，**隔天營運早報列在「新逾期」**；藝人在他的早報看到。你改回 `進行中` 但沒延期的話，下一輪會再改回 `已逾期` |
| **已過截止，等你確認**（M2-14） | **不用交件的任務**（沒勾 `是否開放提交`，例如發文、出席、提大綱）過了死線、你還沒結案 | **狀態不會被改成 `已逾期`**，維持原樣。藝人早報列「⏳ 已過截止，等公司確認」（附「還沒做完請盡快完成；已經做完不用理會」），營運早報列「⏳ 已過截止，等你確認結案」。見「不用交件的任務過了截止」 |
| **每日催辦** | `待審核` 滿 24 小時 | **每天 10:00**，審核人員每人一則，沒填或聯絡不到就發到 `營運內部通知`。藝人端的已逾期、需修改已併進早報 |
| **修改期限逾時** | 過了 `修改期限` 還停在 `需修改` | 營運早報的「修改期限已過」每天列出，直到藝人重交或你改期限 |
| **課後提醒老師** | 專案類型 `課程培訓`、課程結束（`截止日`）滿 2 小時、還沒結案 | 私訊負責老師到論壇發布作業要求與評語，之後每天 10:00 一次，最多 7 天；仍未結案改在營運早報列一次。**同一位老師這一輪有好幾堂課，只收一則**。老師沒有 Discord ID 就列在營運早報請你轉告。**控方需手動到論壇確認老師已發布，再把任務改成 `已完成`；Bot 不會自動偵測論壇貼文。** |
| **發文待確認發布** | 發文類任務停在 `已完成`、截止日過 3 天 | **每週一的營運早報**多一區清單，提醒你確認發布後改成 `已完成發文` |
| **批次重送** | Tasks 勾了 `重送通知` | 下一輪輪詢（≤30 分），重送後自動取消勾選 |
| **本月排程公告** | 自動 | 跟布告欄同步一起，**每 5 分鐘**，有變才更新 |
| **月度時間池催填** | 收集期未填完 | 藝人在**截止前 6 小時**、**逾期後**各收一次私訊；你在營運早報看「已填幾位、還沒填誰」，不再每位藝人填完就跳一則 |
| **月度時間池收齊** | 全員填完 | 立即通知控方，並停止該次收集的檢查 |
| **排課 SLA** | 流程拖太久 | **48 小時**升級通知、**72 小時**提示候選可能失效 |
| **Notion 選項檢查** | bot 每次啟動 | 比對程式拿來篩選的選項（任務狀態、審核狀態、身份類型、會議類型…）在 Notion 還在不在。對不上就在 `營運內部通知` 發一則「⚠️ Notion 選項和程式對不上」，列出少了哪個選項、哪個功能會壞。**通常是有人刪掉或改名了選項，改回原名即可** |
| **Drive 健康檢查** | 自動 | **每天 10:00** 讀一次 Drive 總資料夾。正常不出聲；失敗時在 `營運內部通知` 發一則「⚙️ 系統警告｜Google Drive…」，附原因與修法（一天最多一則）；恢復時同一則改成 🟢 系統恢復。**看到要當天處理，否則藝人交不了件** |
| **布告欄同步** | 自動 | **每 5 分鐘** |

> 💡 **月度時間收集只催兩次**，這是刻意設計避免騷擾藝人。收集期設得長（例如 3 天）的話，中間會有很長一段完全不提醒，需要的話請自行在群組補提醒。

所有重要動作都會寫 `Audit Log`（事件名稱、操作類型、來源系統、操作者、前值後值、目標頁面、結果）。

## 布告欄與本月排程

Notion 的「佈告欄／留言板／使用回饋」會自動同步到 `公告區`，**每 5 分鐘一次**。

想立刻同步就打 **`/布告欄同步`**。

### 本月排程（固定一則）

同一個頻道每個月會有一則「🗓️ YYYY 年 M 月排程」，列出當月所有**已派發**（`Discord 顯示` 有勾）、類型是 `通告`／`演出`、沒有封存的任務。

- 跟布告欄一起每 5 分鐘檢查，**內容有變就改同一則**，不會另發新訊息
- 這則被手動刪掉的話，下一輪（最多 5 分鐘）自動補發，即使排程內容沒有變
- 要讓一筆任務出現：勾 `Discord 顯示`、`任務類型` 選通告或演出、`開始日`（或 `截止日`）落在當月
- 列入的類型跟公告區的公開類型同一個設定（目前是通告、演出；要調整請找工程端）

### 布告欄怎麼同步

- 新增的 Notion 項目 → 發成 Discord 公告
- 改了狀態、類別、日期、人員、置頂 → 更新原訊息
- 沒變的不會重複發

公告下方有「回報／留言」按鈕。使用者送出後，系統在同一個資料庫建一筆：`類別`=🙋 使用回饋、`狀態`=未處理，內容含 Discord 使用者與原公告連結。

## 會議紀錄給小律用（封存中）

> ⏸ **2026-10-18 起封存**：小律只查任務、不讀會議紀錄。以下流程要等工程端恢復會議查詢後才需要做。

藝人可以在 `課程助教` 頻道問小律會議內容。小律只讀得到你照下面做的紀錄：

1. 在 Notion「課程與會議記錄」建一筆，逐字稿或重點**用純文字貼在內頁**（PDF 很耗額度、掃描檔讀不到）
2. `參與藝人` 選這場會議的藝人（沒選的藝人問不到）
3. `會議類型` 選對：選 `課程` 或 `課程會議` 的紀錄**一律不給藝人**（課程內容改走論壇）
4. 確定可以讓藝人知道內容，才勾 `藝人可見`。**公司內部、不想讓藝人知道的會議不要勾**

⚠️ `藝人可見` 這個欄位**不要刪除**（2026-10-18 拍板保留）。它決定小律能不能把內容講給藝人聽；刪了小律會完全查不到，bot 啟動時會在 `營運內部通知` 警告。

藝人也可以問小律自己的任務（「這週有什麼任務」「還有哪些沒交」），範圍跟 `/我的任務` 一樣，只能查不能操作，不需要你另外設定。
藝人問某一筆任務的詳細內容時，小律會把**任務內頁整頁**念給他（略過系統寫的「藝人回覆」「Drive 資料夾索引」，跟派發通知讀的是同一份）。所以**任務內頁不要放不想讓藝人看到的東西**；最多顯示 1,500 字，Notion 網址會被拿掉。
藝人也會問細節（「聽力要做幾題」「要交什麼形式」），小律只根據任務內頁回答，沒寫的會請藝人問你。所以內頁寫清楚**做什麼、做多少、用什麼形式交**（例如「聽力訓練：50 題音程／截圖」）最好用。

## 出問題怎麼查

| 狀況 | 檢查順序 |
|---|---|
| **藝人沒收到通知** | ① `Discord 顯示` 有勾？② 有 `關聯藝人`？③ 藝人 Notion 有填 `Discord User ID`？④ 都有的話打 `/任務通知重送` |
| **同仁沒收到通知** | ① 任務的 `相關同仁` 有填？② People 有填 `Discord User ID`？**沒填 ID 的同仁一定收不到，系統不會另外通知你**（營運早報也不會提醒）③ `Discord 顯示` 有勾？④ 同仁早報只列已逾期、需修改、快到期的任務，沒有這三種就不會發 |
| **老師沒收到課後提醒** | ① 任務的專案類型是 `課程培訓`？② `負責老師` 有填？③ 老師在 People 有 `Discord User ID`？沒有的話會列在營運早報的「老師的課後作業」 |
| **通知發出去了但內容不對** | 先在 Notion 改好欄位（時間要改 `開始日`／`截止日`，不是只改說明文字），再用 `/任務通知重送` |
| **通知寫「尚未填寫任務說明」但內頁有寫** | ① 內容是不是在子頁面裡？（子頁面不讀）② 是不是只有圖片／檔案？（附件不讀）③ 是不是整段都是 `名稱：` 開頭的行？（會被濾掉）④ 都不是的話，可能是 Notion 那一輪讀取失敗，用 `/任務通知重送` |
| **藝人看到不該看的內容** | 內頁整頁都會傳給藝人。把那段移到子頁面，再 `/任務通知重送`；已送出的私訊無法收回 |
| **通知訊息沒有時間** | Task 的 `開始日`／`截止日` 是空的。補上後重送 |
| **重送後藝人說又要再按一次確認** | 正常。重送會清空確認紀錄，內容變了本來就該重新確認 |
| **藝人說看不到 `/我的任務`** | 他在錯的頻道打，只能在 `任務查詢入口` |
| **可排課藝人 0 位** | Artists 有填 `Discord User ID`？`合約狀態` 是不是 `暫停`／`封存`？都對的話請工程端確認 Notion 權限 |
| **比對不到共同空檔** | 月份選錯？有人沒填？時長太長？既有任務佔滿了？ |
| **勾了開放提交但沒通知** | 等一輪輪詢（最多 30 分鐘）；再確認 `Discord 顯示` 也有勾 |
| **審核寫入失敗** | 確認 Submissions 有這四個欄位：`審核回饋`、`審核者`、`審核來源`、`審核通知時間` |
| **管理指令看不到** | 帳號有 Discord 管理員權限嗎？Bot 在線嗎？都正常的話請工程端重開 bot |
| **藝人填錯時間** | 請他自己用 `/管理可配合時間` 刪除重填 |

查不出來時，看 Notion 的 `Audit Log`，裡面有每個動作的成功／失敗紀錄與錯誤訊息。畫面上出現「❌ …失敗，請稍後再試」而 Audit Log 也看不出原因的，把那句話和時間給工程端查 bot 記錄檔。

## 幾條要記得的原則

- **`Availability Slots` 不是正式行程**，只是藝人回報的可配合時間。正式安排一律回到 `Tasks`。
- **TimeTree 不會自動同步**，正式任務確認後人工補登。不一致時以 Notion 為準。
- **不要硬刪 Notion 資料**，系統設計是封存不刪除。
- **任務內頁就是藝人看到的任務說明**，整頁都會被看到；內部資訊放子頁面。
- **改欄位名稱會讓系統失效**。新增資料、新增選項值都安全；**改名、刪欄位、改型別、刪除重建資料庫會出事**，動之前先問。
- **有衝突時以 Notion 正式安排為準**。改時間要保留紀錄，不要直接刪資料庫的頁面。
- **課程時間有異動**：沒有自動的老師確認表單，由你和老師人工協調後，直接在同一筆 Task 改開始／結束時間。

### 哪些是正式行程

| 是正式行程 | 不是正式行程 |
|---|---|
| Notion `Tasks` 中已安排、有明確時間的硬性任務 | `Availability Slots` 的月度可配合時段 |
| 你在 Notion 明確建立的正式 Project／Task | 藝人補填的空檔 |
| | `/從時間池建立任務` 顯示的候選共同空檔 |
